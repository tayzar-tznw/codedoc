# iryo-kanri-system ドキュメント

## はじめに

本プロジェクトは、医療管理、診療報酬計算、患者ポータル、調剤、受付、予約管理など、医療機関における一連の業務プロセスを包括的に支える、堅牢で拡張性の高い医療情報システムのバックエンド基盤です。システム全体としてドメイン駆動設計（DDD）の思想を色濃く反映しており、ビジネスルールを内包する純粋なドメイン層（`domain`）を中心に据え、各業務ドメイン（`billing`、`pharmacy`、`scheduling`、`legacy-claims`）や、具体的なアプリケーション実行層（`admin-console`、`patient-portal`、`reception-desk`）を疎結合に配置する高度なレイヤードアーキテクチャを採用しています。

各コンポーネントは、明確な役割分担のもとで有機的に連携しています。アプリケーションのエントリーポイント群が起動すると、システム全体の共通基盤である `kernel` が提供する監査ログ、セキュリティ、プラットフォーム抽象化などのユーティリティを横断的に利用しながら、データアクセス層（`data`）を介してドメインモデルを操作します。会計や
