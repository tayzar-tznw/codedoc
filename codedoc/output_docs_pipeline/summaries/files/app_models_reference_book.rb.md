本ファイルは、図書館システム等における辞書や百科事典などの「参考図書（ReferenceBook）」を定義するクラスです。データベース設計パターンとして「単一テーブル継承（Single Table Inheritance: STI）」が採用されており、通常の書籍（Book）と同じ `books` テーブルを共有しながら、館外貸出ができない特別な書籍タイプとしてシステム内で区別して扱う役割を担っています。

主要なクラスである `ReferenceBook` は、基底クラスである `Book` クラスを継承して定義されています。そのため、本ファイルは `Book` クラス（通常は `book.rb` などで定義）に依存しています。このクラスの主な責務は、参考図書特有の「館外持ち出し（貸出）ができない」というビジネスルールを、オブジェクト指向のポリモーフィズム（多態性）を利用して表現・強制することです。

重要なメソッドとして、親クラスの挙動をオーバーライドする `loanable?` と `available?` が実装されています。これらのメソッドはどちらも常に `false` を返すように動作し、参考図書が貸出不可であり、貸出可能状態にもならないことを保証します。Rubyのメソッド探索（継承チェーン）の仕組みを利用することで、親クラスの標準的な貸出ロジックを簡潔に上書きしています。
