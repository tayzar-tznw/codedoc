本ファイル（`ebook.rb`）は、電子書籍（Ebook）のデータモデルを定義する役割を持っています。このクラスは親クラスである `Book` を継承しており、データベース設計パターンである単一テーブル継承（STI: Single Table Inheritance）を用いて、物理的な書籍と同じ `books` テーブルに格納・管理されます。

主要なクラスである `Ebook` は、在庫制限のない電子書籍特有の振る舞いを定義する責務を担っています。オブジェクト指向のポリモーフィズム（多態性）を活用し、親クラスのメソッドをオーバーライドすることで、物理的な在庫数に依存しない電子書籍独自の仕様を簡潔に表現しています。

重要なメソッドとして、`available?` と `loanable?` が定義されています。これらのメソッドは物理的な在庫数のチェックをバイパスし、常に `true` を返します。これにより、電子書籍はコピー数が実質的に無制限であり、いつでも利用可能かつ貸出可能であるというビジネスルールをシステム上で実現しています。
