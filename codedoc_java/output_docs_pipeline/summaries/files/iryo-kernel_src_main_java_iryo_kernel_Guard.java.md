本ファイル（Guard.java）は、`iryo.kernel`パッケージに属し、業務APIにおけるメソッド引数の事前条件（バリデーション）を検証するための共通ユーティリティクラスです。不適切な値が渡された際に早期に検出し、システム全体の堅牢性とデータ整合性を担保する役割を担っています。

主要クラスである`Guard`クラスは`final`宣言され、プライベートコンストラクタを持つことでインスタンス化を抑止しています。提供される主要な静的メソッドとして、渡されたオブジェクトが`null`でないかを検証するジェネリックメソッド`notNull`と、文字列が`null`または空白のみでないかを`isBlank`で検証する`notEmpty`が定義されています。いずれのメソッドも、検証に失敗した場合は指定されたパラメータ名を含む`IllegalArgumentException`を送出し、成功時は対象の値をそのまま返却します。

外部ライブラリへの依存関係（import文）は存在せず、標準Java機能のみで完結しています。デザインパターンとしては、静的メソッドのみを提供しインスタンス化を防ぐ「ユーティリティクラス（Utility Class）パターン」を採用しており、プログラムの制御フローにおいて不正な入力を即座に弾く「ガード節（Guard Clause）」の概念を具現化しています。
