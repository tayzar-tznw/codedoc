`ChartEntry.java` は、医療ドメイン（`iryo.domain` パッケージ）においてカルテの1件分の記載情報を表現・保持するモデルファイルです。主要クラスである `ChartEntry` は、患者ID（`patientId`）、カルテの記載内容（`text`）、および記録日時（`writtenAt`）を保持する責務を持ちます。すべてのフィールドが `final` で定義され、状態変更用のセッターを持たないことから、オブジェクトの整合性とスレッドセーフを保証するイミュータブル（不変）パターンが適用されています。

クラス内には2つのコンストラクタが定義されており、引数付きコンストラクタでは患者IDとテキストを受け取り、`LocalDateTime.now()` を用いてインスタンス生成時の現在日時を自動記録します。引数なしコンストラクタはデフォルト値（ID: 0、テキスト: "新規記載"）を指定して引数付きコンストラクタへ処理を委譲（チェーン）します。各フィールドの取得には、Javaのレコード型に類似した命名のゲッターメソッド（`patientId()`, `text()`, `writtenAt()`）が用意されています。

依存関係としては、日時の管理のためにJava標準の `java.time.LocalDateTime` のみをインポートしています。外部ライブラリや他モジュールへの直接の依存を持たない純粋なドメインエンティティであり、電子カルテシステム等のビジネスロジックやリポジトリ層でデータ受け渡しを行うためのデータキャリアとして機能します。
