本ファイルは、受付端末における日次締め処理の手続きを再現し、インポート宣言による名前解決・束縛の違いを実行時に検証するためのプローブ用クラスです。対となる `iryo.probe.xpr.AdminSide` クラスと手続き行のコードを完全に同一に保ちつつ、異なるインポート宣言を用いることで、実行結果の差異がインポート先の定義に依存することを実証する役割を担っています。

主要クラスである `ReceptionSide` の唯一の公開メソッド `run()` は、ロガーによる「日次点検」の出力記録、バリデータによる患者ID等の検証、および点数計算ユーティリティによる点数から金額（円）への変換を行い、それぞれの処理結果を文字列配列として返却します。依存関係として `iryo.billing.Validator`、`iryo.billing.PointMath`、`iryo.kernel.logging.Logger` をインポートしており、受付側コンテキストにおける課金・監査モジュールと連携しています。

設計面では、クラスが `final` で宣言され、コンストラクタが `private` に隠蔽されていることから、インスタンス化を禁止して静的メソッドのみを提供する「ユーティリティクラス（Utility Class）パターン」が採用されています。
