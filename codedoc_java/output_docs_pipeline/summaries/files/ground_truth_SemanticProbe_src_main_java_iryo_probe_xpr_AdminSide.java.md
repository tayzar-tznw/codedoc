`AdminSide.java`は、管理コンソール側の手続きを再現し、インポート宣言による型の束縛先と実行時挙動の違いを検証・証明するためのプローブクラスです。対となる`ReceptionSide`クラスとコード手続きを完全に一致させながら異なる依存先をインポートすることで、実行時の動作分岐がテキストの内容ではなくインポート宣言に起因することを実証する役割を担っています。

本ファイルの中核である`AdminSide`クラスは、唯一の公開静的メソッドとして`run()`を提供しています。このメソッド内では、`iryo.pharmacy`パッケージの`Logger`によるログ記録、`Validator`によるコード検証、`PointMath.toYen()`によるポイント換算手続きを順次実行し、それぞれの結果をまとめた文字列配列（ログメッセージ、検証フラグ文字列、計算された金額文字列）を返却します。

設計面では、明示的にプライベートコンストラクタを定義して外部からのインスタンス化を防止する「Utility Classパターン」が採用されています。依存関係としては`iryo.pharmacy`配下の各クラスを利用しており、同パッケージの`ReceptionSide`と同一処理を異なるコンテキスト（インポート）で評価するための比較対象として機能しています。
