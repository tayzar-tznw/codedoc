`StandardPolicy.java` は、医療ドメイン（`iryo.kernel` パッケージ）において支払いに関する手数料算定方針を定義するクラスファイルです。主要クラスである `StandardPolicy` は `final` クラスとして宣言されており、追加の加工を行わずに既定の事務手数料をそのまま適用する標準的な運用ルール（方針）を表現する責務を担っています。

本クラスは明示的なメソッドを保持しておらず、実装している同一パッケージの `PaymentPolicy` インターフェースのデフォルト実装をそのまま利用する、あるいは型による識別を目的とした設計となっています。明示的な外部インポートは存在せず、同パッケージ内の `PaymentPolicy` と密接に関連しています。

アーキテクチャの観点では「Strategyパターン（ポリシーパターン）」が採用されており、`PaymentPolicy` を戦略インターフェース、本クラスをその具体的な戦略（Concrete Strategy）として位置付けています。手数料計算ルールをカプセル化することで、他の計算方針との柔軟な差し替えを可能にしています。
