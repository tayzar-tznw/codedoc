本ファイル（ReceiptFormatter.java）は、旧世代のレセプトコンピュータ（レセコン）との互換性を保った領収書テキストの整形処理を提供するユーティリティクラスです。パッケージ `iryo.legacy.claims.text` に属しており、レガシーな医療請求システム向けのテキストフォーマット処理を担当します。

主要なクラスである `ReceiptFormatter` は継承を禁止する `final` クラスとして定義されており、領収書アイテムの文字列表現を旧レセコン形式へ変換する単一の責務を持ちます。中心となる `format(Object item)` メソッドは、受け取った任意のオブジェクトに対してプレフィックス「[旧レセ] 」を付与した文字列を生成して返却します。

外部ライブラリや他クラスへのインポート（依存関係）は存在せず、標準Java機能のみで完結する疎結合な設計となっています。デザインパターンとしては、出力形式の変換処理を独立したコンポーネントとして切り出すフォーマッタ（Formatter）パターンを採用しており、整形ロジックをカプセル化するストラテジー（Strategy）パターンの具象クラスとしても利用可能な構造となっています。
