`VitalSequence.java`は、医療レポーティングシステム（`iryo.reporting`パッケージ）において、一連のバイタルデータ（整数値）を業務ルールに沿って連続的に処理・変換することを目的としたユーティリティクラスです。主要クラスである`VitalSequence`は、内部で保持する数値リスト（`List<Integer>`）の操作をカプセル化し、データの抽出、変換、集計を安全かつ直感的に行う責務を持ちます。

提供される重要なメソッドとして、指定された条件に合致する要素のみを抽出する`filter`、各要素に関数を適用して値を変換する`map`、および全要素の合算値を算出する終端操作の`total`が存在します。`filter`および`map`は処理結果を基に新しい`VitalSequence`インスタンスを生成して返すため、元のオブジェクトの状態を変更することなくメソッドチェーンによる柔軟なデータパイプライン処理を実現します。

外部ライブラリや他プロジェクトファイルへの依存はなく、Java標準ライブラリの`java.util.List`、`ArrayList`、および関数型インターフェースである`Function`や`Predicate`のみに依存しています。設計面では、状態の改変を防ぎスレッドセーフを確保する「不変（Immutable）オブジェクトパターン」や、メソッドチェーンによる直観的な記述を可能にする「Fluent Interfaceパターン（流れるようなインターフェース）」が採用されています。
