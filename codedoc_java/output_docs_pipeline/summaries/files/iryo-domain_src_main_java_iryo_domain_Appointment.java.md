本ファイルは、医療システムにおける診察予約のデータを表現・管理するドメインモデルです。主要クラスである`Appointment`は、予約ID（`id`）、患者ID（`patientId`）、および予約日時（`slot`）を不変の状態で保持する責務を担っており、デザインパターンとして「イミュータブルオブジェクト（不変オブジェクト）」パターンおよびドメイン駆動設計（DDD）におけるエンティティを採用しています。クラスおよび全フィールドが`final`として宣言されているため、生成後の状態変更を防ぎ、スレッドセーフな安全性を確保しています。

重要なメソッドとしては、各プロパティを取得するアクセサメソッド（`id()`、`patientId()`、`slot()`）に加え、予約情報を整形して可視化する`summary()`が提供されています。`summary()`メソッドは、静的な`DateTimeFormatter`を利用して予約日時を「yyyy-MM-dd HH:mm」形式に変換し、「予約[id] (患者[patientId] / [slot])」という形式の要約文字列を生成します。

外部依存関係はJava標準ライブラリの日時API（`java.time.LocalDateTime`および`DateTimeFormatter`）のみに留められており、外部ライブラリやフレームワークに依存しないクリーンな構成となっています。`iryo.domain`パッケージに属し、他のサービス層やリポジトリ層から予約情報の参照・引き渡しを行う中核モデルとして利用されることを意図しています。
