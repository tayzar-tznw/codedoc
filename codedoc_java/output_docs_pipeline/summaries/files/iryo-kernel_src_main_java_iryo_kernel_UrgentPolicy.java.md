`UrgentPolicy.java`は、医療システムにおいて時間外診療や急患時における支払いルール（手数料率や割増率）を定義するためのソースコードです。本ファイルに含まれる`UrgentPolicy`クラスは、`PaymentPolicy`インターフェースを実装するイミュータブルな具象クラス（`final`クラス）であり、GoFのStrategy（ストラテジー）パターンにおける具体的な計算戦略を提供する責務を担っています。

クラス内に定義された唯一のメソッドである`fee()`は、時間外・急患の条件に応じた追加比率として固定値`0.25`（25%に相当）を`double`型で返却します。外部ライブラリ等の明示的なインポート文は存在せず、同一パッケージ（`iryo.kernel`）内の`PaymentPolicy`インターフェースのみに依存しており、診療費の計算や請求処理を行う上位コンポーネントに対して動的に差し替えて適用される関係となっています。
