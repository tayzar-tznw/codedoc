本ファイルは、外部システム連携処理において患者IDのフォーマットを統一・正規化することを目的としたユーティリティクラスです。提供される`PatientIdKit`クラスは、`final`修飾子と`private`コンストラクタを適用してインスタンス化を禁止しており、静的メソッドのみを提供する「ユーティリティクラスパターン（Utility Class Pattern）」に則って実装されています。

主要なメソッドである`normalize(String raw)`は、引数として受け取った患者ID文字列の前後空白をトリムし、ロケール非依存（`Locale.ROOT`）で大文字に変換した上で、含まれる空白文字をハイフン（`-`）に置換して返却します。外部ライブラリへの依存はなく、標準の`java.util.Locale`のみをインポートしており、医療情報連携パッケージ（`iryo.interop`）内で安全かつ一貫したID照合・データ連携を支える基礎コンポーネントとして機能します。
