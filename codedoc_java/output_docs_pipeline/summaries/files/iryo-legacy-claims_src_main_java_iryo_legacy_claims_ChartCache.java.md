本ファイルは、旧来のレセコン（レセプトコンピュータ）処理系において単一の値を一時的に保持・管理するための簡易キャッシュ機能を提供するものです。中心となる`ChartCache<T>`クラスは`final`修飾されたジェネリッククラスとして定義されており、任意の型のデータを型安全に1件のみカプセル化して保持する責務を担っています。

主要なメソッドは、保持している値を取得する`get()`と、新しい値を格納（上書き）する`put(T value)`の2点のみで構成されています。外部ライブラリや他クラスへのインポート依存は一切なく、独立した最小限の実装となっています。主に`iryo.legacy.claims`パッケージ内の請求・カルテ処理コンポーネント間で、特定の処理単位における単一データの一時保管や値の受け渡しのために参照されます。

アーキテクチャ面では、オブジェクト参照をラッピングして保持・受け渡しを行う「Value Holder（ホルダー）」パターンが採用されています。キャッシュサイズ制限、有効期限（TTL）、スレッドセーフ（排他制御）などの高度な機能は持たず、レガシーシステムにおける局所的で軽量なデータコンテナとしてシンプルに設計されています。
