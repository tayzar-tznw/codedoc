`ShadowSide.java` は、受付端末の実装におけるスコープ遮蔽（シャドウイング）構造を再現し、Java言語仕様（JLS 6.4.1）に基づく静的インポートと自クラス内メソッドの優先解決規則を実行時に検証するためのクラスです。本ファイル内の主要クラスである `ShadowSide` は `final` 修飾され、プライベートコンストラクタによってインスタンス化を抑止するユーティリティクラス（Utility Class パターン）として設計されています。

本クラスは `iryo.billing.PointMath` の静的メソッド `toYen`（10倍計算）をインポートしつつ、同シグネチャの独自メソッド `toYen(int)`（11倍計算）をプライベートで定義しています。提供される公開メソッドのうち、`shadowed` は非修飾名で呼び出すことで自クラス側の定義が静的インポートを遮蔽する挙動を、`imported` は完全修飾名を用いて静的インポート元の正規処理へ正しくバインドする挙動をそれぞれ実証・比較する役割を担っています。
