本ファイルは、旧来の単一パッケージ構成（`iryo.kernel`）を採用している既存端末向けに提供された、ロガーの後方互換性を維持するためのラッパークラスです。新しい業務コードでは `iryo.kernel.logging.Logger` を直接利用することが推奨されており、本クラスは既存システムがパッケージ構成の変更による影響を受けずにログ機能を利用し続けられるようにする窓口としての責務を担っています。

実装されている `Logger` クラスは `final` 修飾され、新パッケージの実装である `iryo.kernel.logging.Logger` を継承しています。クラス内には独自のログ出力ロジックは存在せず、引数なしのデフォルトコンストラクタ `Logger()` と、ログの所有者名を指定する `Logger(String owner)` のみが定義されており、いずれも対応する親クラスのコンストラクタを呼び出すことで初期化処理をそのまま委譲しています。

構造としては、パッケージ移行時のインターフェース互換性を維持するための Adapter パターン（あるいは互換窓口としての Facade パターン）が適用されています。親クラスである `iryo.kernel.logging.Logger` に強く依存しており、移行期間中の互換レイヤーとして最小限のコードで機能を提供しています。
