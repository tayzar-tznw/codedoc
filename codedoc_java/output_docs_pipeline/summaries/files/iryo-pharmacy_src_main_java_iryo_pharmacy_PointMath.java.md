本ファイル（PointMath.java）は、医療・調剤システムにおいて薬価点数を院内レートに基づいて日本円へ換算することを目的としたユーティリティファイルです。主要クラスである`PointMath`は、院内における点数から円への換算ロジックを一元管理し、計算処理を提供する責務を担っています。

提供されている唯一のメソッド`toYen(int points)`は、引数の薬価点数に院内レートである10.8を乗算し、`Math.ceil`により小数点以下を切り上げて整数値（円）を算出・返却します。依存関係については外部ライブラリや他ファイルへのインポートはなく、標準ライブラリの`java.lang.Math`のみを利用した自己完結型の構成となっています。

設計面では「ユーティリティクラス（Utility Class）パターン」が適用されています。クラス宣言に`final`修飾子を付与して継承を禁止し、コンストラクタを`private`に設定してインスタンス化を抑止することで、静的（static）メソッドのみで構成される純粋な関数型ヘルパークラスとして機能させています。
