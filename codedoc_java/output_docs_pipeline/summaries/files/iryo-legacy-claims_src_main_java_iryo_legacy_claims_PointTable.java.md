本ファイルは、レガシーな医療費請求処理において経過措置加算を含めた点数計算を行うことを目的としたクラスです。主要クラスである `PointTable` は、バージョン1.0以降で非推奨（`@Deprecated`）に指定されており、将来的な削除予定はないものの、過去の仕様に基づく点数表の計算ロジックを保持・提供する責務を担っています。

中心となるメソッドは `calculate(int a, int b)` です。このメソッドは2つの整数を引数として受け取り、それらの合計値に経過措置加算とみられる固定値「1000」を加算した結果を返却する単純な計算処理を実行します。

本クラスは外部ライブラリや他パッケージのインポートを行っておらず、依存関係を持たない独立した実装となっています。パッケージ名（`iryo.legacy.claims`）から、旧来の請求システム内の他コンポーネントから呼び出される関係であることが推測されます。なお、コード規模が極めて小さいため顕著なデザインパターンは適用されていませんが、単一の計算ロジックを提供するシンプルなサービスクラスとして機能しています。
