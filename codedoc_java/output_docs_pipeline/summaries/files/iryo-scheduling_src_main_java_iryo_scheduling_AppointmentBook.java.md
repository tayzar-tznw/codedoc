`AppointmentBook.java`は、医療システム等における確定済みの予約情報をインメモリで管理・保持するための台帳クラスです。パッケージ`iryo.scheduling`に属し、システム内における予約データの追加や、特定の患者に関連付けられた予約件数の集計といった状態管理の責務を担っています。

主要クラスである`AppointmentBook`は、内部で`Appointment`のリストをカプセル化して保持しています。主要なメソッドとして、新規予約をリストへ登録して追加された予約を返す`reserve`メソッドと、リスト内を走査して指定された患者ID（`patientId`）に一致する予約数をカウントする`countFor`メソッドが実装されています。依存関係としては、ドメインモデルである`iryo.domain.Appointment`を参照し、そのプロパティを利用して処理を行います。

設計面では、コレクション（`List<Appointment>`）とその関連操作を専用のクラスにカプセル化する「ファーストクラスコレクション」のパターンが適用されています。また、データの保管と検索を担う構造から、簡易的な「インメモリ・リポジトリ（Repository）パターン」としても機能しており、データ整合性と独立性を高める構成となっています。
