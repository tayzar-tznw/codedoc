`PaymentPolicy.java`は、支払い処理における事務手数料の算出方針を規定するためのインターフェースです。`iryo.kernel`パッケージに属し、外部ライブラリ等のインポート依存は存在しません。ドメインの中核（カーネル）において、手数料算出に関する共通の契約を定義し、システム全体で一貫した支払いルールの適用を促す役割を担っています。

本インターフェースで定義されている主要なメソッドは`fee()`と`policyName()`の2点です。`fee()`はデフォルトメソッドとして実装されており、個別の実装クラスで上書きされない限り、標準の事務手数料率として5%（0.05）を返します。また、ユーティリティ的な静的メソッドである`policyName()`は、既定のポリシー名称である「既定方針」の文字列を返却します。

設計面ではStrategyパターンの戦略インターフェースとしての役割を果たしています。手数料の計算ロジックをカプセル化し、要件に応じて異なる手数料ポリシー（例：割引方針や固定額方針など）を実装クラスとして差し替え可能にすることで、既存コードを変更することなく振る舞いを拡張できる設計となっています。
