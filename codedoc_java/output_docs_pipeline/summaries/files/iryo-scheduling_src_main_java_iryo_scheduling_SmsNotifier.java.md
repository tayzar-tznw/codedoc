本ファイルは、予約管理システムにおいてSMS（ショートメッセージサービス）を用いた通知機能を提供するクラスを定義しています。`iryo.scheduling`パッケージに属し、予約部門が利用者を対象としてSMSによるメッセージ伝達を行う具象的な通知処理の責務を担っています。

主要な構成要素である`SmsNotifier`クラスは、`iryo.kernel`パッケージの`Notifier`インターフェースを実装した`final`クラスです。重要メソッドである`send(String msg)`は、引数として受け取ったメッセージ文字列を標準出力へフォーマットして出力することで、SMS送信処理を実行（シミュレート）します。

設計面では、`Notifier`インターフェースに対する具象実装としてStrategyパターン（ストラテジーパターン）が採用されており、通知アルゴリズムをカプセル化することで、他の通知手段（メール等）との容易な切り替えや疎結合なシステム設計を実現しています。
