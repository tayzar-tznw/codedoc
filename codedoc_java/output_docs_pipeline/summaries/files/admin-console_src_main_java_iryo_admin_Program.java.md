本ファイルは、医療管理システムにおける管理コンソールアプリケーションのエントリーポイント（起動点）を提供するクラスです。主要クラスである `Program` は `final` 修飾子が指定され、`private` コンストラクタによりインスタンス化が禁止されたユーティリティクラス（Static Utility Class）パターンとして設計されており、管理バッチ処理の一連の流れを統括して実行する責務を担っています。

中心となる `main` メソッドでは、同一パッケージ（`iryo.admin`）内の他ファイルに定義されている `DailyBatch.run()` と `ReportDigest.run()` を順次呼び出します。これにより、日次バッチ処理およびレポートダイジェスト処理を自動的に実行し、処理の開始と完了のメッセージを標準出力へ表示する動作を行います。外部ライブラリへの依存はなく、同パッケージの業務処理クラスと密接に連携する構成となっています。
