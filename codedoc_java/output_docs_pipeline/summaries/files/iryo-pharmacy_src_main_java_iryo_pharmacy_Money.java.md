本ファイルは、薬局管理システムにおいて医薬品などの在庫評価額を安全かつ明確に表現することを目的としたドメインモデルです。主要クラスである `Money` は、在庫の金額情報を保持する責務を持ち、金銭というドメイン概念を単なる数値型ではなく専用の型としてカプセル化しています。

クラス内の実装は極めてシンプルであり、重要なメソッドとしてはコンストラクタ `Money(BigDecimal amount)` のみが定義されています。このコンストラクタは引数として受け取った金額を公開不変フィールド `amount` に設定します。外部依存関係としては高精度な数値計算を保証するために `java.math.BigDecimal` のみをインポートしており、フレームワーク等に依存せず、同一パッケージ（`iryo.pharmacy`）内の在庫管理や会計関連のクラスから利用されることを想定しています。

設計面では、ドメイン駆動設計（DDD）における「値オブジェクト（Value Object）」パターンが適用されています。クラス自体が `final` で宣言され、内部状態を保持するフィールドも `final` に指定されているため、インスタンス生成後に状態が変化しないイミュータブル（不変）な構造となっており、金銭データの整合性と安全性が担保されています。
