本ファイルは、医療管理システムにおいて週次の脈拍傾向データおよび収益状況を集計・出力することを目的としたファイルです。主要クラスである `ReportDigest` は `final` 修飾子と `private` コンストラクタを備えており、インスタンス化を抑止して静的メソッドのみを提供する「ユーティリティクラス（Utility Class）パターン」を採用して実装されています。

クラス内に定義された主要メソッド `run()` は、週次ダイジェストのコンソール出力を担います。内部では、サンプルの脈拍データ（70, 88, 64）に対してJava Stream APIを用いて65を超える値を抽出後、基準値60を引いた超過分の合計値を算出・表示します。さらに、外来および入院の費用を合算して週間の総収益を計算し、結果を出力します。

外部依存関係として、ドメイン層の金額計算を担う `iryo.domain.Money` クラスや `java.math.BigDecimal` を利用して安全な金額演算を行っているほか、レポート出力用の共通部品である `iryo.reporting.KarteKit.heading` を静的インポートして見出しのフォーマットを行っています。医療ドメインのエンティティや共通ユーティリティと連携し、管理用の集計ビューを生成する役割を果たしています。
