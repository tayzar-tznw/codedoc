`DoseCalculator.java`は、患者の体重と体重あたりの投与基準量（単位用量）に基づき、一回あたりの薬の投与量を算出することを目的としたクラスファイルです。`iryo.pharmacy`パッケージに属し、投薬量の計算ロジックを提供する計算コンポーネントとしての責務を担っています。

本ファイルの主要クラスである`DoseCalculator`は`final`修飾子により継承が禁止されており、唯一の公開メソッドである`calculate(int weightKg, int mgPerKg)`を備えています。このメソッドは患者の体重（kg）と体重1kgあたりの投与量（mg）を引数として受け取り、それらを乗算した一回あたりの総投与量（mg）を整数値で返却します。

外部ライブラリや他の独自クラスに対するインポート（依存関係）は存在せず、完全に自己完結したコードとなっています。明確なGoF等のデザインパターンは適用されていませんが、インスタンス変数を持たないステートレスな設計となっており、純粋な計算処理をカプセル化したドメインサービスとして機能します。
