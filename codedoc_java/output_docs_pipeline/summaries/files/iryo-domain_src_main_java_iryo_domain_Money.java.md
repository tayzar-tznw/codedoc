`Money.java`は、ドメイン層（`iryo.domain`）において円建ての金銭データを表現するための不変な値オブジェクト（Value Object）です。Javaのレコード（`record`）機能を用いて実装されており、ドメイン駆動設計（DDD）のValue Objectパターンおよびイミュータブルパターンを採用することで、金額計算における副作用の排除とデータの整合性を担保しています。

主要クラスである`Money`は、金額を保持・操作する責務を持ちます。コンパクトコンストラクタでは`Objects.requireNonNull`を用いて`amount`のnullチェックを行い、無効な状態の生成を防ぎます。`plus`メソッドは他の`Money`オブジェクトとの加算結果を新しいインスタンスとして返却し、`toString`メソッドは`BigDecimal#toPlainString`を利用して指数表記を避けつつ「〇〇円」の形式で文字列表現を生成します。

外部依存は標準ライブラリである`java.math.BigDecimal`と`java.util.Objects`のみであり、高精度な数値計算と安全な検証を実現しています。このクラスはフレームワーク等に依存せず自己完結しており、金銭を扱う各種ドメインモデルや集約から汎用的に利用される基礎的な部品として機能します。
