本ファイル（Logger.java）は、調剤台帳システムにおいて調剤処理専用のログメッセージをメモリ上で保持・管理することを目的としたユーティリティクラスです。主要クラスである`Logger`は、記録対象のメッセージに特定のフォーマットを適用して内部リストに蓄積し、蓄積されたログデータを外部から安全に参照できるようにする責務を持ちます。

主要なメソッドとして、受け取ったメッセージの先頭にプレフィックス「[調剤] 」を付与して内部のリストに追加する`log(String message)`と、記録された全ログ行を返す`lines()`が存在します。`lines()`では`Collections.unmodifiableList`を使用しており、外部からの内部リストの直接変更を防ぐ「変更不能ビュー（Unmodifiable View）」パターンが適用され、カプセル化とデータの整合性が保たれています。

依存関係としては、Java標準ライブラリの`java.util.ArrayList`、`Collections`、`List`のみを利用しており、外部フレームワークへの依存はありません。本クラスは`iryo.pharmacy`パッケージ内に配置されており、同一パッケージ内の処方・調剤処理を実行するドメインクラス群からイベント記録用として利用されることを想定しています。
