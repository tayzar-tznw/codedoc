`ReceiptFormatter.java` は、医療会計システム（`iryo.billing.text` パッケージ）において、現行会計用の領収書表示テキストを整形するためのコンポーネントです。主要クラスである `ReceiptFormatter` は `final` 修飾子により継承が禁止されており、領収書項目の文字列表現を加工・標準化する責務を担っています。

本クラスの唯一のメソッドである `format(Object item)` は、引数として受け取った任意のオブジェクトの文字列表現の先頭に `"[会計] "` という接頭辞を付与した文字列を返却します。外部ライブラリや他パッケージへの明示的なインポートは存在せず、Javaの標準クラス（`java.lang` パッケージ）のみに依存したシンプルで自己完結した実装となっています。

設計面においては、出力形式の整形ロジックを独立させてカプセル化する Formatter パターンや、領収書整形の振る舞いを差し替えるための Strategy パターンの具象クラスとしての性格を備えています。状態を保持しないステートレスな構造となっており、請求・会計処理の出力層におけるテキスト生成処理から呼び出される構成となっています。
