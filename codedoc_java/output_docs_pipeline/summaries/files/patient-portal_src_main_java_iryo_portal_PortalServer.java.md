本ファイルは、患者向けの予約および診療料金照会機能を提供する軽量なHTTPサーバー「`PortalServer`」を定義しています。`PortalServer`クラスは、Java標準の`HttpServer`を用いてWebAPIのエンドポイントを構築し、外部からのHTTPリクエストの受信、ドメインロジックの呼び出し、クライアントへのレスポンス生成を統括するコントローラーとしての責務を担っています。

主要なメソッドとして、エンドポイント（`/appointments`、`/fees`）のルーティングを設定するコンストラクタおよびサーバーを起動する`start`メソッドを備えています。リクエスト処理を担当する`handleAppointments`は新規予約の確定と通知送信を行い、`handleFees`は診療点数および日本円への料金計算と通知送信を実行します。共通処理である`respond`メソッドにより、UTF-8形式のプレーンテキストとしてHTTPレスポンスを一元的に返却します。アーキテクチャ面では、予約・請求・通知といった複数サブシステムの処理を集約して外部に公開するFacadeパターンの役割を果たしているほか、通知機能において`Notifier`インターフェースを介して`MailNotifier`を扱うインターフェース分離（ポリモーフィズム）が適用されています。

依存関係として、標準の`com.sun.net.httpserver`パッケージを活用するほか、業務ロジック層の`AppointmentBook`や`Appointment`（スケジュール管理）、`FeeCalculator`や`PointMath`（請求計算）、`Notifier`および`MailNotifier`（通知基盤）と密接に連携しており、システム全体の各ドメインサービスを統合する役割を果たしています。
