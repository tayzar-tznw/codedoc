`AccountingFlow.java`は、医療受付業務における診療点数の計算から患者への請求・受領、および領収書発行に至る一連の会計処理を実行・検証するためのサービスクラスです。主要クラスである`AccountingFlow`は、インスタンス化を防ぐプライベートコンストラクタを備えたフロー制御クラスであり、内部には手数料計算ルールの多重継承競合を明示的に解決するプライベートクラス`CombinedPolicy`および`ReviewPolicy`インターフェースが定義されています。

唯一の公開メソッドである`run()`は、会計フロー全体のオーケストレーションを担います。`FeeCalculator`を用いた多様なオーバーロード計算メソッドの実行、`Money`オブジェクトによる金額の加算と受領処理、点数の円換算および丸め処理、各種領収書フォーマッタによる出力生成、旧システムとの点数突合処理などを順次実行します。アーキテクチャ面では、分散したサブシステムを一元的に呼び出すFacade（ファサード）パターンとしての役割を持ち、手数料率の切り替えには`PaymentPolicy`をインターフェースとしたStrategyパターンが適用されています。

依存関係として、会計計算モジュール（`iryo.billing`）、ドメイン金額モデル（`iryo.domain.Money`）、手数料規約を司る基幹モジュール（`iryo.kernel`）、および後方互換性・外部連携を担う各パッケージ（`iryo.legacy.claims`、`iryo.pharmacy`、`iryo.interop`）と広く連携しています。新旧の点数表やフォーマッタを併用して動作を突合するなど、システム間・世代間の相互運用性を確認・実行する中心的な役割を果たしています。
