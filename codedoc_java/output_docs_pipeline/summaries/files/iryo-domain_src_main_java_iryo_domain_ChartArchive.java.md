本ファイルは、医療ドメインにおけるカルテの長期保管庫を表現する `iryo.domain.ChartArchive` クラスを定義しています。外部ライブラリへの明示的な依存（import）はなく、独立したドメインモデルとして設計されており、クラス自体は `final` で宣言されているため継承による拡張は制限されています。

本クラスの責務はカルテ保管庫自体の表現に加え、関連する保守タスクを内包することです。具体的には、独立したバックグラウンド処理としてアーカイブ圧縮を担う静的ネストクラス `Compactor` と、保管庫インスタンスに紐付いて保管索引の清掃を担当するインナークラス `Janitor` が定義されています。それぞれの主要メソッドとして、`Compactor.start()` は圧縮処理の開始を、`Janitor.clean()` は索引の清掃処理を実行します。

設計面では、関連する補助機能を外部に出さずに閉じるネストクラスの構造が採用されています。インスタンス状態に依存しない処理（`Compactor`）と、外側の保管庫インスタンスに束縛される処理（`Janitor`）を静的・非静的インナークラスとして適切に使い分け、カプセル化と高い凝集性を実現しています。
