本モジュール（`iryo-domain/src/main/java`）は、医療管理システムにおける中核的な業務ルールとドメイン概念を表現・統括するドメイン層のJavaソースコードルートです。外部フレームワークやインフラストラクチャへの依存を排除した純粋なオブジェクト指向設計を基軸とし、患者管理、診察予約、電子カルテ記録、金銭計算、病棟管理といった医療業務全般のビジネスロジックとデータ構造を体系的に定義・保護することを目的としています。

内部のコンポーネントは、基盤となるエンティティクラス群（`Entity`、`AuditedEntity`）を頂点として密接に連携しています。中核エンティティである `Patient`（患者）に対し、`Appointment`（予約）や `ChartEntry`（カルテ記載）が参照関係を保持して診療プロセスをモデル化し、さらに `ChartArchive` がカルテの保管・ライフサイクル管理を補完します。これに高精度な計算を保証する値オブジェクト `Money` や、病棟管理を担うサブパッケージ群が組み合わさることで、診療から会計、病棟運用に至る複雑な業務フローを整合性を維持したまま自己完結的に処理しています。

アーキテクチャ面ではドメイン駆動設計（DDD）が徹底されており、エンティティと値オブジェクトの厳密な峻別や、副作用を排除して並行処理安全性を高めるイミュータブルパターンの採用が特徴的です。また、オブジェクトの安全な生成・複製を実現する Static Factory Method や Prototype パターンの適用、内部クラスによるカプセル化の強化、関心の分離（SoC）を具現化したパッケージ構成など、変更に強く長期的な保守性と信頼性を担保する堅牢なドメインモデルが確立されています。
