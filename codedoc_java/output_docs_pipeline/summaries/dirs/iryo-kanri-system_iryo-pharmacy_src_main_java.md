本ディレクトリは、医療管理システムにおける薬局・調剤ドメイン（`iryo-pharmacy`）のJavaプロダクションコードのルート基盤として機能し、配下の名前空間を通じて調剤業務の中核をなすビジネスロジック、データ表現、計算処理を提供します。処方指示の妥当性確認をはじめ、体重に基づく適正投与量の算出、薬価点数から費用への換算、安全な金銭計算、調剤イベントの監査ログ追跡に至るまで、調剤ワークフローに必要な中核機能を包括的に集約・カプセル化することを目的としています。

配下のコンポーネントは、一連の調剤業務プロセスに沿って密接に協調動作します。外部から処方データを受け取ると、`Validator` が構文および業務規則の検証を実施し、検証済みのデータに対して `DoseCalculator` が患者特性に応じた安全な投与量を算出します。さらに、`PointMath` が薬価点数と院内レートに基づく費用換算を行い、その金銭情報は不変な値オブジェクトである `Money` により高精度かつ安全に保持されます。これら一連の処理経過は `Logger` を介してインメモリに記録され、監査証跡とトレーサビリティが確立されます。

アーキテクチャ面では、外部ライブラリやフレームワークに依存せずJava標準APIのみで構築された、自己完結型でポータビリティの高いクリーンな設計が徹底されています。副作用を排除するステートレスなユーティリティクラス群や不変（Immutable）値オブジェクトパターンの採用、コレクションの防御的コピーによるカプセル化など、堅牢性とテスタビリティを最大化するための設計原則が一貫して適用されています。
