本ディレクトリ（`src`）は、医療管理システムにおけるグラウンドトゥルース検証フレームワーク「SemanticProbe」のソースコード全体を統括するルートディレクトリです。調剤や請求といった複雑な業務モジュールの境界において、Java言語仕様に準拠した型推論、オーバーロード解決、インポート規則、およびスコープ遮蔽（シャドウイング）などのコンパイラセマンティクスが仕様通りに機能しているかを、製品コードに変更を加えることなく実行時に決定論的に実証・評価することを目的としています。

傘下の `main` ソースツリーでは、オーケストレーターである `probe.Program` を起点とし、静的インポートの隠蔽を検証する `shadow` や、インポート先に応じた挙動差を追跡する `xpr`（`AdminSide`、`ReceptionSide`）などの特化型プローブ群が有機的に連携して駆動します。各コンポーネントは、リフレクションや `SerializedLambda` を駆使してコンパイル時に静的バインドされたシグネチャ記述子を実行時に動的抽出・照合することで、静的解決と実行時ディスパッチの整合性を高精度に検証する協調関係を構築しています。

アーキテクチャ設計としては、検証結果の決定論的な再現性を担保するため、可変状態や副作用を徹底排除する方針が貫かれています。各検証ロジックには `final` 修飾および非公開コンストラクタによるユーティリティクラスパターンが徹底されており、名前空間の意図的な競合や特殊な名前解決規則をサブモジュール単位で厳密にカプセル化しています。これにより、ストラテジーパターンなどを交えながら、システム全体の安定性を脅かすことのない安全かつ拡張性の高いテストベッドを実現しています。
