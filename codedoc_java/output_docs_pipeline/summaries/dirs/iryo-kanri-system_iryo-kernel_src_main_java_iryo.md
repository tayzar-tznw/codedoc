本ディレクトリ（`iryo`）は、医療管理システム全体を支える中核基盤モジュール「iryo-kernel」のルートパッケージであり、システム共通の規約、ドメインポリシーの抽象定義、および汎用的な実行インフラ機能を提供することを目的としています。外部ライブラリへの依存を排除しJava標準APIのみで構築されており、業務ロジックや上位アプリケーション層から分離された独立性の高いプラットフォームとして、システムの整合性と移植性を担保しています。

配下の `kernel` サブパッケージを中心に、軽量な依存性注入（DI）機構、ドメイン戦略、および堅牢化ユーティリティの3つの系統が有機的に連携して動作します。基底となる `ServiceCollection` と `ServiceProvider` がコンポーネントのライフタイム管理とコンストラクタインジェクションによる依存解決を司り、その基盤上で通知仕様を抽象化する `Notifier`（具象：`MailNotifier`）や、診療手数料の算定ルールを定義する `PaymentPolicy`（具象：`StandardPolicy`、`UrgentPolicy`）が動的に協調動作します。さらに、事前条件検証を行う `Guard` やロギング機構が、システム横断的な安定性と保守性を支援しています。

アーキテクチャの観点では、上位モジュールが具象ではなく抽象に依存する「依存性逆転の原則（DIP）」と、業務ルールの差し替えを容易にする「Strategyパターン」が中核に据えられています。また、Fluent APIによる宣言的なサービス登録、早期リターンを促進するガード節、リフレクションを用いた依存解決、および後方互換性を維持するAdapter/Facadeパターンなど、変更に強くテスタビリティと堅牢性を兼ね備えた設計判断が一貫して適用されています。
