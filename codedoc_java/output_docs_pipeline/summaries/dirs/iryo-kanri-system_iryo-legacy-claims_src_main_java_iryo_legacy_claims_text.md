本ディレクトリ（`iryo.legacy.claims.text`）は、レガシー医療請求システムにおいて、旧世代のレセプトコンピュータ（レセコン）との互換性を確保するためのテキスト整形処理を集約するモジュールです。システム内で扱われる医療請求や領収書データを、旧規格に準拠した特定の文字列表現へ変換・加工する責務を担っており、レガシー環境向け出力の標準化を図ることを目的としています。

主要なコンポーネントとして `ReceiptFormatter` が配置されており、任意の領収書アイテムを受け取って旧レセコン形式のプレフィックスを付与した文字列へ変換する役割を果たします。本モジュールは外部ライブラリや他クラスに依存しない自己完結型の疎結合な構成となっており、クラスを `final` として定義することで意図しない継承や振る舞いの変更を防止しています。アーキテクチャ面では、出力変換ロジックを分離・カプセル化するフォーマッタ（Formatter）パターンを採用しており、請求処理パイプラインにおいて柔軟に差し替え可能なストラテジー（Strategy）の一端としても機能する堅牢な設計となっています。
