本ディレクトリ（`iryo-scheduling/src/main`）は、医療管理システムにおける予約管理（スケジューリング）モジュールの本番用ソースコード群を統括するルートディレクトリです。その主たる目的は、患者の予約受付から確定、通知に至るスケジューリング業務全般のビジネスロジックと関連処理を提供し、予約プロセスの信頼性とデータの整合性を一元的に担保することにあります。

内部の`java`ディレクトリ配下では、予約ドメインモデルと外部連携コンポーネントが密接に協調して動作します。予約エンティティの集約や業務ルールの検証・管理を担う`AppointmentBook`が、新規予約の登録や患者ごとの予約状態の追跡を行い、予約の確定などの状態遷移イベントに連動して`SmsNotifier`が患者へのメッセージ送信を実行します。これにより、予約ライフサイクルの管理から患者向けコミュニケーションまでがシームレスに連携した業務フローを形成しています。

設計面では、関心の分離と将来の拡張性を重視したアーキテクチャパターンが採用されています。`AppointmentBook`にファーストクラスコレクションおよびインメモリ・リポジトリパターンを適用することで、予約操作とビジネスルールをカプセル化し、ドメインの整合性を保護しています。さらに、通知機能には基盤層のインターフェースに基づいたStrategyパターンを採用しており、中核のドメインロジックと具体的な通信手段を疎結合に保つことで、永続化層の変更や将来的な通知チャネルの追加にも柔軟に対応できる堅牢な構造を実現しています。
