`iryo.pharmacy`パッケージは、医療管理システムにおける薬局・調剤ドメインの核となる基本検証、計算処理、データ表現を提供するモジュールです。処方箋データの構文チェックから患者に応じた投与量算出、薬価点数に基づく費用換算、金銭の安全な型表現、調剤イベントの追跡に至るまで、調剤ワークフローに必要な最小限かつ堅牢なドメインロジックとユーティリティを集約しています。

内部のコンポーネント群は、調剤業務プロセスを構成する一連の処理として協調・補完し合う関係にあります。`Validator`による処方指示の妥当性検証を起点に、`DoseCalculator`が患者体重に基づく安全な投与量を算出し、`PointMath`が薬価点数から院内レートに沿った円換算を実施します。これらの処理で扱われる金額や評価額は不変クラスである`Money`によって高精度かつ安全にモデル化され、一連の調剤アクションの経過は`Logger`を通じてメモリ上に改ざん不可能な形で記録・管理されます。

アーキテクチャ上の特徴として、外部ライブラリやフレームワークへの依存を完全に排除し、Java標準ライブラリのみで構成された自己完結型のクリーンな設計が徹底されています。設計面では、`final`修飾子の多用とコンストラクタ制御による「ユーティリティクラス」や「値オブジェクト（Value Object）」パターンの採用、状態を持たないステートレスな計算サービス、および`Collections.unmodifiableList`による防御的カプセル化（変更不能ビュー）が適用されており、高い堅牢性、不変性、およびテスタビリティが確保されています。
