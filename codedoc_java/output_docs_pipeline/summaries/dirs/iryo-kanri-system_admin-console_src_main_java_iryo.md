本ディレクトリ（`iryo`）は、医療管理システムにおける管理コンソールアプリケーション（admin-console）のJavaソースコードのルート名前空間であり、システム運用に必要な定期バッチ処理や集計・監査レポート出力機能の基盤を提供することを全体的な目的としています。直下には業務ロジックを統括する `admin` パッケージを配置し、管理者向けコンソール機能の実装をカプセル化しています。

本モジュールの中核となる `admin` ディレクトリでは、システムのエントリーポイントである `Program` を起点として処理がオーケストレーションされます。`Program` のメインルーチンから、日次点検タスクを担当する `DailyBatch` と、週次のバイタルおよび収益データを集計する `ReportDigest` が順次呼び出される構成となっています。これらのコンポーネントは、調剤層（`iryo.pharmacy`）、ドメイン層（`iryo.domain`）、およびレポート共通層（`iryo.reporting`）といった外部モジュールの機能を横断的に呼び出し、業務ドメインに即した一連の管理処理を実現しています。

アーキテクチャ上の設計判断として、コンソール・バッチ処理を担うクラス群はインスタンス化を抑止したユーティリティクラスパターン（`final` クラスおよびプライベートコンストラクタの適用）で統一されています。ステートレスな静的メソッドによる実行モデルを採用することで、状態管理に伴う副作用を排除し、コマンドラインからの確実かつ安全なバッチタスク実行と高い保守性を両立しています。
