本ディレクトリ（`iryo-kanri-system/iryo-billing/src/main/java`）は、「iryo-billing」モジュールにおけるJavaソースコードのルートディレクトリであり、医療管理システムにおける診療報酬請求および窓口会計処理のコアビジネスロジックをホストすることを目的としています。直下にファイルは配置せず、主要ドメインを包括するルートパッケージ（`iryo`）とその配下のサブパッケージ群によって、公的医療保険制度に準拠した点数計算、法定換算レートに基づく金額算出、入力バリデーション、領収書・請求書帳票の生成といった一連の会計ドメインの責務を構造化して集約しています。

配下のコンポーネントは、会計・請求処理の一連のパイプラインとして密接に連携しています。まず `Validator` が保険証情報や請求対象データの妥当性を検証し、検証を通過したデータに対して `FeeCalculator` が診療報酬点数の集計や各種割引ロジックを適用します。続いて `PointMath` が計算された点数を法定レート（1点＝10円）と規定の端数処理ルールに従って確定金額へと変換し、最終的に `ReceiptFormatter` が算出結果を患者向けの領収書や請求書テキストとして整形・出力します。これらのコンポーネントが処理フローに沿って純粋に関数的に接続されることで、高精度な会計処理パイプラインを実現しています。

アーキテクチャ面では、Validator、Calculator、Formatter、Utility Classといった役割に応じた厳密な責務分離が図られています。すべての主要コンポーネントにおいてステートレス設計とクラスの不変性（`final` 化）を徹底することで、マルチスレッド環境下における高い安全性と並行処理耐性を確保しています。さらに、外部サードパーティライブラリへの依存を排除してJava標準仕様のみで自己完結させる方針を採用しており、制度改定や点数マスターの変更に対しても副作用を最小限に抑え、長期的な保守性と移植性を高める堅牢な基盤を構築しています。
