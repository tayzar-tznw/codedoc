`iryo.interop` モジュールは、医療管理システムにおける外部システム連携（相互運用性）を担う中核レイヤーです。本モジュールは、外部システムへの提出やデータ交換に必要とされる各種データの生成、出力フォーマットの変換、および連携キーとなる識別子の標準化・正規化を包括的に支援することを目的としています。

モジュール内部では、データ出力処理の共通契約として `Exporter` インターフェースを定義し、CSV形式を担う `CsvExporter` やXML形式を担う `XmlExporter` などの具象クラスが連携して動作します。また、安全かつ一貫したデータ照合を実現するために `PatientIdKit` が患者IDの表記揺れを吸収・正規化する役割を果たし、さらに `text` サブパッケージのフォーマッター群（`ReceiptFormatter` 等）と組み合わさることで、外部提出データの正確な構築パイプラインを支えています。

アーキテクチャ面では、Strategyパターンを採用して出力フォーマットの切り替えや将来的なフォーマット追加を容易にする拡張性を確保しています。同時に、各クラスを `final` として宣言したり、ユーティリティクラスのインスタンス化を禁止するなど、意図しない継承や改変を防ぐ防御的設計が徹底されています。外部ライブラリへの依存を排除し標準Javaのみで自己完結させることで、高い可搬性と保守性、テスト容易性を備えた疎結合な設計を実現しています。
