本ディレクトリ（`iryo-pharmacy/src/main`）は、医療管理システムにおける薬局・調剤モジュールのプロダクションソースコードを統括するルートディレクトリです。その主要な目的は、調剤業務の中核をなすビジネスルール、計算エンジン、ドメインデータモデルの実装を集約・管理し、システム全体に対して安全かつ一貫した調剤ドメイン機能を提供することにあります。外部からの処方指示の受け入れから、適正な投与量の算出、点数・金銭計算、監査ログの保持に至るまで、調剤ワークフローに必要な中核ロジックを包括的にカプセル化しています。

配下のJavaソースコード群は、調剤パイプラインの各フェーズに応じて密接に連携します。入力された処方データは `Validator` によって構文および業務制約の厳格な検証が行われ、妥当性が保証されたデータに対して `DoseCalculator` が患者の体重等に基づき安全な投与量を算出します。続いて `PointMath` が薬価点数と換算レートに基づいた費用計算を実行し、金銭情報は不変値オブジェクトである `Money` を介して安全に取り扱われます。これら一連のワークフローで発生するイベントは `Logger` によりインメモリで追跡・蓄積され、業務監査とトレーサビリティを確立します。

アーキテクチャ上の設計判断として、外部フレームワークへの依存を排した自己完結型のクリーンな設計が徹底されています。計算や検証を担うステートレスなユーティリティクラスの採用と、値オブジェクトパターンによる不変性（イミュータビリティ）の担保、防御的コピーによるデータのカプセル化が図られており、業務の正確性と堅牢性、並びにテスタビリティを最大限に高めた構造となっています。
