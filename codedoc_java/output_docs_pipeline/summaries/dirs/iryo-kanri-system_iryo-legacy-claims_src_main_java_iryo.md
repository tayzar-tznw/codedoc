本モジュール（`iryo`）は、医療管理システムにおける旧世代のレセプトコンピュータ（レセコン）や過去の請求仕様に対する後方互換性機能を一元管理・カプセル化するための基盤ルートパッケージです。現行システムへの移行期におけるデータ照合や既存業務の継続性を担保しつつ、旧仕様固有の業務ロジックが現行のコア業務ドメインへ侵食することを防ぐ防腐層（Anti-Corruption Layer）としての役割を担っています。

配下の主要コンポーネント群は、旧仕様に特化した請求処理パイプラインを形成して連携しています。算定処理の中核である `legacy.claims` 配下の `OldTable` や `PointTable` が旧点数表や経過措置加算に基づく計算を担い、算定データは軽量な `ChartCache` を介して安全に受け渡されます。そして最終的に `ReceiptFormatter` によって旧レセコン仕様に準拠したテキスト形式へと整形・出力されることで、完結したレガシー請求出力フローを実現しています。

アーキテクチャ面では、将来的なレガシー機能の安全な廃止・切り離し（サンセット）を前提とした設計方針が貫かれています。外部依存を極力排除した自己完結型の構成とし、Value HolderやFormatterといった責務を明確に分担するパターンの採用に加え、クラスへの `@Deprecated` 付与や `final` 修飾による無秩序な拡張・新規利用の抑止など、システムの堅牢性と保守性を最優先にした防御的プログラミングが徹底されています。
