本ディレクトリは、医療管理システムにおける薬局・調剤ドメインのJavaソースコードのルート名前空間を定義し、配下の`pharmacy`サブパッケージを通じて調剤業務の中核をなすデータ表現、ビジネス検証、および各種計算処理を提供するモジュールです。処方指示の妥当性確認から、体重に基づく安全な投与量計算、薬価点数による費用換算、金銭の精密な表現、調剤イベントの追跡に至るまで、調剤ワークフローに必要な基盤ロジックを包括的に集約・カプセル化することを目的としています。

配下に配置された各コンポーネントは、一連の調剤業務プロセスを支える協調関係を形成しています。処方箋データを受け取った`Validator`が構文および業務ルールを検証し、その結果をもとに`DoseCalculator`が患者ごとの適正な投与量を算出します。続いて`PointMath`が薬価点数から院内レートに応じた金額への換算を行い、その金銭情報は不変な値オブジェクトである`Money`によって精度と安全性を担保しながら表現されます。これら一連の調剤アクションの経過は`Logger`を通じてインメモリに記録され、トレーサビリティが確保されます。

アーキテクチャ面では、フレームワークや外部ライブラリへの依存を排除したJava標準APIのみによる自己完結型のクリーンな設計が徹底されています。不変性を保証する値オブジェクトパターンやプライベートコンストラクタを持つステートレスなユーティリティクラスの採用、`Collections.unmodifiableList`を用いた防御的コピーによるカプセル化など、堅牢性とテスタビリティを最大化するための設計判断が一貫して適用されています。
