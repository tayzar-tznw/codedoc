`iryo-data` モジュールは、医療管理システムにおけるデータアクセス層を担い、患者情報や電子カルテをはじめとする医療データの永続化処理およびキャッシュ機構を提供するモジュールです。ドメイン層やアプリケーション層などの上位ビジネスロジックに対してリレーショナルデータベースやストレージ技術の具体的な実装詳細を隠蔽し、安全で高信頼なデータアクセス基盤を確立することを目的としています。

内部では、データアクセスの抽象契約を定める `Repository<T>` インターフェースを中心に、RDB向けの具象実装である `SqlPatientRepository` やオブジェクト生成を担う `RepositoryFactory` および `Registry` が連携して動作します。さらに、参照頻度の高いカルテ情報に対して高速アクセスを提供する `ChartCache` が組み合わされており、データ整合性を担保しながらトランザクション処理のパフォーマンスを最適化する構造となっています。

アーキテクチャ設計においては、ドメイン駆動設計（DDD）のRepositoryパターンを採用することで、ビジネスロジックと永続化機構の完全な疎結合化を実現しています。また、Static FactoryパターンやCacheパターンの適用、コンストラクタインジェクションを通じた依存性管理により、高いテスタビリティと保守性を確保しており、将来的なデータストアの変更やキャッシュ戦略の拡張にも柔軟に適応可能な設計となっています。
