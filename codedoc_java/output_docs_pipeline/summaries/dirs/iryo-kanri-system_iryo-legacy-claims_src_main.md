本ディレクトリ（`iryo-legacy-claims/src/main`）は、医療管理システムにおいて旧世代レセプトコンピュータ（レセコン）仕様や過去の診療報酬請求ルールに対する後方互換性を一元的にカプセル化するためのメインソースコードルートです。新旧システムの移行期におけるデータ照合や既存業務の継続性を担保しつつ、旧仕様固有の複雑なビジネスロジックが現行のコアドメインへ混入することを防ぐ「防腐層（Anti-Corruption Layer）」としての役割を担っています。

内部構造は配下のJavaソースコード群を中心に、旧仕様に特化した自己完結型のパイプラインとして構成されています。算定の中核を担うコンポーネント群（`OldTable` や `PointTable`）が過去の点数表や経過措置に基づく請求計算を実行し、その算定結果は軽量なキャッシュ機構（`ChartCache`）を介して安全にデータ連携されます。最終的に専用のフォーマッタ（`ReceiptFormatter`）が旧レセコン仕様に準拠したテキスト形式への変換と出力を担うことで、計算から出力まで一貫したレガシー請求処理フローを提供しています。

アーキテクチャ面では、将来的なレガシー機能の安全な切り離し・廃止（サンセット）を容易にすることを最優先とした設計判断がなされています。外部依存を最小限に抑えた責務分離パターンを採用するとともに、クラスへの `@Deprecated` 付与や `final` 修飾による継承の抑止など、防御的プログラミングを徹底することで、新規開発コードからの意図しない依存やレガシーロジックの拡散を防ぐ堅牢な構造を確立しています。
