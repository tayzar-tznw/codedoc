本モジュール（`iryo-legacy-claims/src/main/java`）は、医療管理システムにおける旧世代レセプトコンピュータ（レセコン）仕様や過去の診療報酬請求ルールに対する後方互換性機能を一元的にカプセル化するためのソースコードルートです。新旧システムの移行期におけるデータ照合や既存業務の継続性を担保しつつ、旧仕様固有の複雑なビジネスロジックが現行のコアドメインへ混入することを防ぐ「防腐層（Anti-Corruption Layer）」としての重要な役割を担っています。

内部構造としては、配下の `iryo` パッケージを中心に旧仕様に特化した独立パイプラインを構築して連携しています。算定処理の中核となる `OldTable` や `PointTable` が過去の点数表や経過措置加算に基づく計算を担い、その算定結果は軽量な `ChartCache` を介して安全にデータ連携されます。最終的に `ReceiptFormatter` が旧レセコン仕様に準拠したテキスト形式への変換と出力を担うことで、入力から出力まで完結したレガシー請求処理フローを提供しています。

アーキテクチャ面では、将来的なレガシー機能の安全な切り離し・廃止（サンセット）を最優先とした設計判断がなされています。外部依存を最小限に抑えた自己完結型の構成とし、Value HolderやFormatterといった責務分離パターンを採用しています。さらに、クラスへの `@Deprecated` アノテーション付与や `final` 修飾による継承・拡張の抑止など、システムの堅牢性を維持し新規コードからの無秩序な利用を防ぐ防御的プログラミングが徹底されています。
