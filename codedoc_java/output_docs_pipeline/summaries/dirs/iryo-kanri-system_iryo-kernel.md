本モジュール（`iryo-kernel`）は、医療管理システム全体の中核的基盤を担う共通インフラストラクチャです。外部フレームワークやサードパーティ製ライブラリに依存せず、Java標準APIのみで完結する設計を採用しており、上位の業務ロジックやインフラ実装から完全に独立したアーキテクチャ境界を形成しています。システム共通の依存性注入（DI）機構、ドメインポリシーの抽象仕様、および堅牢な汎用ユーティリティを集約することで、システム全体の高い移植性、保守性、およびテスタビリティを保証することを主目的としています。

モジュール内部は、自作の軽量DIコンテナを中心に各コンポーネントが密接に連携しています。基幹となる `ServiceCollection` と `ServiceProvider` がコンポーネントのライフサイクル管理とコンストラクタインジェクションによる依存解決を司り、その基盤上で診療報酬等の算定ルールを抽象化した `PaymentPolicy` や通知基盤である `Notifier` などの各種インターフェース・サービスが動的に解決・連携動作します。さらに、横断的関心事として早期リターンによる厳格な入力値検証を担う `Guard` やロギング機能が組み込まれており、各コンポーネント間における安全なデータ流通と堅牢な実行環境を確立しています。

アーキテクチャ面では、上位層が具象実装ではなく抽象に依存する「依存性逆転の原則（DIP）」と、業務ルールの柔軟な差し替えを可能にする「Strategyパターン」が徹底されています。また、Fluent APIによる宣言的なサービス登録やリフレクションを活用した疎結合なインスタンス生成、後方互換性を維持するAdapterやFacadeパターンの採用など、外部依存を排除しながらもエンタープライズ領域における拡張性と保守性を両立する高度な設計判断が適用されています。
