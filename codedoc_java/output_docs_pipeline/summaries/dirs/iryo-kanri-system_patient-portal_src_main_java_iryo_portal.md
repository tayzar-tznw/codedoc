`iryo-kanri-system/patient-portal/src/main/java/iryo/portal`モジュールは、患者向けポータル機能のエントリーポイントとしてWeb APIを提供する軽量なHTTPサーバーレイヤーです。Java標準のHTTPサーバー機能を活用して構築されており、患者からの予約リクエストの受付や診療報酬点数に基づく料金照会といった主要機能を外部に公開し、クライアントとの通信インターフェースを一元管理することを目的としています。

本ディレクトリの中核を成す`PortalServer`は、ルーティングおよびリクエスト処理のコントローラーとして機能します。受信したHTTPリクエストに応じて、スケジュール管理（`AppointmentBook`など）、診療報酬・料金計算（`FeeCalculator`、`PointMath`）、通知基盤（`Notifier`、`MailNotifier`）といった独立した業務ドメインサービスを適切に呼び出し、処理結果をプレーンテキストのHTTPレスポンスとして統合・返却するオーケストレーションを担っています。

アーキテクチャ上の判断として、予約・請求・通知という異なるサブシステムの機能をクライアントに対して単純化して提供するFacadeパターンが採用されています。また、通知機能においては`Notifier`インターフェースを介したポリモーフィズムを適用することで通知手段の疎結合性を担保し、外部フレームワークに依存せずJava標準ライブラリ（`com.sun.net.httpserver`）を利用することで、シンプルで保守性の高いアーキテクチャ設計を実現しています。
