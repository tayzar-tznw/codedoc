`iryo-kanri-system/patient-portal/src` は、患者向けポータル機能の実装資産を統括するソースルートディレクトリです。中核を担う `main` モジュールを通じて、患者が外部ネットワークから安全に利用できるWebインターフェースおよびAPI機能の実行基盤を提供しており、予約管理、診療費自己負担額の照会、各種完了通知といった患者向けサービスのリクエスト受付からレスポンス生成に至るエンドツーエンドの処理を実現することを全体的な目的としています。

モジュール内部では、バックエンドロジックとサーバー機能を担う `java` 領域と、プレゼンテーション資産を保持する `webapp` 領域が配置されています。主要コンポーネントである `PortalServer` がHTTPエンドポイントとしてクライアントからの要求を集中ハンドリングし、予約管理、請求計算、通知基盤などの業務ドメインをFacadeパターン経由でオーケストレーションします。一方で、旧来の画面生成を担っていた `webapp` 内のJSP等の資産は現行の `PortalServer` からは直接参照されず、近代化に伴う移行確認・参照用として安全に隔離された状態で共存しています。

アーキテクチャ上の重要な判断として、重量級フレームワークを排してJava標準のHTTPサーバー機能を活用することで、ランタイムの軽量化と高い可搬性を実現している点が挙げられます。また、Facadeパターンを適用してバックエンドの複雑な業務ロジックを隠蔽し、ドメイン間の疎結合性を維持する設計が採られています。レガシーなWebリソースを即時破棄せずに段階的な移行プロセスを担保する構成をとることで、保守性と移行時の安全性を高度に両立させたアーキテクチャとなっています。
