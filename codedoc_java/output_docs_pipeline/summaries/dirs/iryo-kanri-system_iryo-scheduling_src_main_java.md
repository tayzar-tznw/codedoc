本ディレクトリ（`iryo-scheduling/src/main/java`）は、医療管理システムにおける予約管理（スケジューリング）機能の中核を成すJavaソースコードのルートディレクトリです。その全体的な目的は、予約受付から確定・患者連絡に至る一連の業務フローを司るドメインモデルおよび関連処理を提供し、予約業務の安全な遂行とデータ整合性の維持を一元的に管理することにあります。

内部では、配下のパッケージに属する主要コンポーネントが協調して動作します。予約データの集約・管理を担う`AppointmentBook`が新規予約の登録や患者単位での予約状況の追跡・整合性チェックを行い、予約の確定といったイベントに連動して`SmsNotifier`が患者へのメッセージ送信処理を実行します。これにより、予約状態のライフサイクル管理と外部への連絡処理がスムーズに連携するアーキテクチャを構築しています。

設計上の判断として、関心の分離と将来の拡張性を担保するデザインパターンが採用されています。`AppointmentBook`にはファーストクラスコレクションおよびインメモリ・リポジトリパターンが適用され、予約データ操作とビジネスルールをカプセル化してドメインの整合性を保護しています。また、`SmsNotifier`は基盤層のインターフェースに基づくStrategyパターンの具象クラスとして実装されており、中核の予約ロジックから具体的な通知手段を疎結合に保つことで、将来的な通知チャネルの追加や永続化方式の変更にも柔軟に適応できる堅牢な構造を実現しています。
