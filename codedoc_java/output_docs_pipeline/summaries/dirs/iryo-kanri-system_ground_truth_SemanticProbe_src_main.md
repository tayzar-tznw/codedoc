本ディレクトリ（`src/main`）は、医療管理システムにおけるグラウンドトゥルース検証ツール「SemanticProbe」の中核実装を統括するソースルートです。調剤系や請求系をはじめとする複雑な業務モジュールの境界において、Java言語仕様に準拠した型推論、オーバーロード解決、インポート規則、およびスコープ遮蔽（シャドウイング）が仕様通りに機能しているかを、製品コードに手を加えることなく実行時に決定論的に実証・評価することを目的としています。

配下の `java` ディレクトリに含まれるコンポーネント群は、オーケストレーターである `probe.Program` を起点として有機的に連携します。静的インポートのメソッド隠蔽を検証する `shadow` パッケージや、インポート先の相違による挙動変化を追跡する `xpr` パッケージ（`AdminSide`、`ReceptionSide`）などの特化型プローブが順次駆動されます。さらに、実行時には `SerializedLambda` やリフレクションを活用してコンパイラが静的にバインドしたシグネチャ記述子を動的に抽出・照合することで、コンパイル時セマンティクスと実行時ディスパッチの整合性を高精度に検証します。

アーキテクチャ設計としては、検証結果の決定論的再現性を保証するために可変状態や副作用を徹底排除する方針が採られており、各プローブクラスには `final` 修飾と非公開コンストラクタによるユーティリティクラスパターンが徹底されています。また、ストラテジーやファクトリなどのデザインパターンを取り入れつつ、名前空間の意図的な競合や特殊な名前解決規則をサブモジュール単位で厳密にカプセル化することで、システム全体の安定性を損なうことなく安全なテストベッドを実現しています。
