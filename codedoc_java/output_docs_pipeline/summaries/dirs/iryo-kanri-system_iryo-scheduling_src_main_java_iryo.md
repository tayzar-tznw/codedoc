本モジュール（`iryo-scheduling/src/main/java/iryo`）は、医療管理システムにおける予約管理（スケジューリング）機能のルート名前空間として位置づけられ、配下の`scheduling`パッケージを通じて予約業務の中核ロジックを提供することを目的としています。システムにおける予約データの安全な登録・追跡機能と、予約手続きに伴う患者向け通知処理を統合し、予約受付から確定・連絡に至る一連の業務フローを実行する責務を担っています。

配下の主要コンポーネントとして、予約ドメインモデルを集約・管理する`AppointmentBook`と、メッセージ送信処理を担う`SmsNotifier`が連携して機能します。`AppointmentBook`が新規予約の受け付けや患者ごとの予約状況の集計・整合性管理を行う一方で、予約確定等のイベントに応じた患者への直接連絡を`SmsNotifier`が担当することで、予約状態の更新と外部通知が協調して動作する構造となっています。

アーキテクチャ面では、関心の分離と将来の拡張性を重視した設計判断が下されています。`AppointmentBook`にはファーストクラスコレクションおよびインメモリ・リポジトリパターンが適用され、予約データ操作をカプセル化してドメインルールの整合性を保護しています。また、`SmsNotifier`は共通基盤インターフェース（`iryo.kernel.Notifier`）に基づくStrategyパターンの具象クラスとして実装されており、通知機能とドメインロジックを疎結合に保つことで、将来的な通知手段の追加や永続化機構の変更にも柔軟に適応できる堅牢な設計を実現しています。
