本ディレクトリ（`iryo-kanri-system/patient-portal/src/main/java/iryo`）は、患者向けポータル機能を提供するサブシステムの中核Javaパッケージであり、患者が外部からシステムへアクセスするためのWebインターフェースおよびAPIの提供を統括することを目的としています。配下の`portal`パッケージを中心に、クライアントからのリクエスト受付から業務処理の実行、レスポンス返却までの一連の処理フローをカプセル化し、患者向けの予約管理や料金照会といった機能を外部に公開するエントリーポイントとして機能します。

内部アーキテクチャの中心となるのは、`portal`モジュールに含まれる`PortalServer`です。このコンポーネントがコントローラー兼オーケストレーターとして機能し、HTTPエンドポイントを通じて受信した患者リクエストをハンドリングします。受信したリクエストの内容に応じて、スケジュールを管理する予約サービス、診療報酬点数から自己負担額を算出する料金計算サービス、そして処理完了を伝える通知基盤といった各種ドメインサービスを協調動作させ、クライアントに対して統合された結果を返却します。

設計面においては、複数の独立したサブシステム（予約・請求・通知）に対するアクセス窓口を単一化するFacadeパターンが採用されており、クライアントに対する複雑性の隠蔽とインターフェースの単純化が図られています。また、重量級のWebフレームワークに依存せず、Java標準のHTTPサーバー機能（`com.sun.net.httpserver`）を採用することでランタイムの軽量化と高い保守性を実現しつつ、通知処理におけるインターフェースの活用などにより、各ドメイン機能との疎結合性を担保したアーキテクチャ設計となっています。
