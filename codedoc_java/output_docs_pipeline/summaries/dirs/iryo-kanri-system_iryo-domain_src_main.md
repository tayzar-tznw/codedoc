本ディレクトリ（`iryo-domain/src/main`）は、医療管理システムにおけるコアビジネスロジックとドメイン知識を集約したドメイン層のメインソースルートです。外部のデータベースやUI、フレームワークへの依存を完全に排除した純粋なドメインモデルを構築・管理することを目的としており、下位のJavaソースツリーを通じて患者管理、診察予約、電子カルテ、医療費計算、病棟管理といった多岐にわたる医療業務の概念と厳密な業務規則を一元的に定義しています。

内部では基盤となる監査・識別エンティティ（`Entity`、`AuditedEntity`）を共通基盤とし、中核となる患者（`Patient`）エンティティを中心に診察予約（`Appointment`）や電子カルテ記録（`ChartEntry`）、カルテ保管（`ChartArchive`）などの診療系コンポーネントが密接に連携しています。さらに、高精度な金銭計算を担う値オブジェクト（`Money`）や病棟管理を担当するサブドメイン群が協調することで、患者の受け入れから診療プロセスの追跡、病棟運用、会計処理に至る一連の医療業務フローを、高い整合性を保ちながら自己完結して処理する構造を形成しています。

アーキテクチャ面ではドメイン駆動設計（DDD）の原則が徹底されており、エンティティと値オブジェクトの厳格な分離や、並行処理耐性と安全性を高めるイミュータブルパターンの採用が顕著です。また、安全なオブジェクトライフサイクル管理のための Static Factory Method や Prototype パターンの活用、内部クラスによるカプセル化、関心の分離（SoC）に基づくパッケージ分割など、将来的なシステム拡張や仕様変更に耐えうる堅牢性と高い保守性を両立した設計判断が下されています。
