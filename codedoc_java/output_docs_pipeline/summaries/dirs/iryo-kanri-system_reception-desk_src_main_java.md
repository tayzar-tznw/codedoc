本モジュール（`iryo-kanri-system/reception-desk/src/main/java`）は、医療管理システムにおける受付端末アプリケーションのソースコードルートディレクトリであり、配下の `iryo` パッケージを通じてシステム全体の初期化および各種受付業務シナリオのライフサイクルを統括・実行することを目的としています。来院受付から会計、調剤連携、日次締め処理に至る受付デスクの一連の運用プロセスを束ねるエントリーポイントとして機能し、エンドツーエンドの業務機能を提供します。

内部アーキテクチャにおいては、中心となる `Program.java` が合成ルート（Composition Root）として振る舞い、DIコンテナを介してロギング、通知、データアクセスなどのインフラストラクチャサービスを初期化・構成します。初期化されたサービス群を基盤に、`CheckInFlow`（来院受付）、`AccountingFlow`（会計・領収書発行）、`PharmacyFlow`（調剤連携）といった `flows` 配下の各業務フローコンポーネントを駆動させ、ドメイン層や外部・旧システム連携層などの独立したサブシステム間を調停・オーケストレーションします。

設計面では、Composition Root パターンと依存性の注入（DI）を徹底することで具象実装間の結合度を抑え、モジュール全体の保守性とテスト容易性を担保しています。また、各業務フローを状態を持たない Facade 的なコンポーネントとしてカプセル化し、純粋なドメインロジックと上位の業務オーケストレーションを明確に責務分離しています。これにより、複雑な医療受付業務における事前条件の検証や外部連携の整合性担保をフロー層に集約し、堅牢で拡張性の高い構造を実現しています。
