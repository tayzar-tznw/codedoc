本ディレクトリ（`iryo-kanri-system/patient-portal/src/main`）は、患者向けポータルサブシステムの中核を成すソースコードおよびWebリソースを集約したメインモジュールです。患者が外部ネットワークからシステムへ安全かつ円滑にアクセスするためのWebインターフェースおよびAPI機能の実装基盤を提供し、予約管理や診療費の自己負担額照会、各種完了通知といった患者向けサービスのリクエスト受付からレスポンス生成までの一連のエンドツーエンド処理を統括することを目的としています。

モジュール内は、バックエンド処理とサーバー機能を担う `java` ディレクトリと、従来のWebプレゼンテーション資産を保持する `webapp` ディレクトリによって構成されています。アーキテクチャの中心となるのは `java` 配下の `PortalServer` であり、HTTPエンドポイントを通じて受信したクライアントからの要求をハンドリングするコントローラーおよびオーケストレーターとして機能します。このサーバーが予約サービス、請求計算サービス、通知基盤といった複数の業務ドメインをFacadeパターンを通じて統合・制御しています。一方で `webapp` 配下のJSPテンプレートは旧来のMVCにおけるView層の成果物ですが、現行の `PortalServer` 主体のアーキテクチャからは切り離されており、現在は直接的な動的連携を行わない参照用・移行用の静的アセットとして隔離されています。

設計面における特徴として、重量級フレームワークに依存せずJava標準のHTTPサーバー機能を活用することで、ランタイムの軽量化と高い可搬性を実現している点が挙げられます。また、Facadeパターンの適用により各業務ドメイン間の疎結合性を維持し、クライアントに対してバックエンドの複雑な業務ロジックを隠蔽しています。さらに、旧Web資産を即座に破棄せず段階的な移行確認用として維持する構造を採用しており、システムの近代化と安全性を両立させるアーキテクチャ上の配慮が反映されています。
