本ディレクトリ（`iryo-kanri-system/reception-desk/src`）は、医療管理システムにおける受付端末アプリケーションのソースコードのルート基盤です。来院受付、会計・領収書発行、調剤連携、日次締め処理など、受付業務に求められるエンドツーエンドの業務プロセスを実行可能なプログラムとして集約・管理し、安定したデスクワーク運用の遂行を支えることを目的としています。

内部では、配下の `main` ディレクトリに配備された各種コンポーネントが密接に連携しています。エントリーポイントである `Program.java` がシステムの起点としてDIコンテナを用いた初期化と依存関係の解決を一括して行い、ロギングやデータアクセスといったインフラストラクチャ層を立ち上げます。その基盤上で、`CheckInFlow`、`AccountingFlow`、`PharmacyFlow` などの業務フローコンポーネントが起動し、ドメインロジックや外部・レガシーシステム連携層を適切に調停・オーケストレーションすることで、一貫した業務トランザクションを成立させています。

アーキテクチャ面では、Composition Root パターンと依存性の注入（DI）を採用することで具象クラス間の結合度を最小限に抑え、保守性とテスト容易性を向上させています。また、各業務フローを Facade 的なコンポーネントとしてカプセル化することで、純粋なドメインルールと上位の業務進行責務を明確に分離し、医療受付特有の厳密な事前条件チェックや外部連携時の整合性を堅牢に担保する設計判断が下されています。
