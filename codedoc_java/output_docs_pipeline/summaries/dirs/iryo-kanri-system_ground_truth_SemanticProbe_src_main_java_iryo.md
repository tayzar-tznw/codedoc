本ディレクトリ（`iryo`）は、医療管理システムにおけるグラウンドトゥルース検証ツール「SemanticProbe」のJavaルート名前空間であり、製品コードに変更を加えることなく、Java言語仕様に準拠した型推論、オーバーロード解決、インポート規則、スコープ遮蔽（シャドウイング）の正当性を実行時に決定論的に実証するための検証基盤を提供します。配下に配置された `probe` モジュールを通じて、調剤系や請求系など複雑な業務モジュール間連携や境界条件におけるセマンティクスが、仕様通りに振る舞うかを網羅的に検証することを目的としています。

内部の主要な構成として、中核エントリポイントである `probe.Program` が全体の検査シナリオを統括し、特化されたサブモジュールと有機的に連携します。具体的には、静的インポートによるメソッド隠蔽ルールを実証する `shadow` パッケージや、同一コードがインポート先の相違によって異なる挙動へ分岐することを検証する `xpr` パッケージ（`AdminSide`、`ReceptionSide`）を順次実行してその整合性を照合します。さらに、`SerializedLambda` を利用してコンパイラがバインドしたシグネチャ記述子をリフレクション経由で動的に特定・検証することで、静的型解決から動的ディスパッチに至る挙動の正確性を高度に評価します。

アーキテクチャ上の判断としては、テスト対象の振る舞いから可変状態などの外部要因を排除するため、各プローブに対して `final` 宣言および非公開コンストラクタによるユーティリティクラスパターンが徹底されています。また、DIコンテナ、ストラテジー、ファクトリといった各種デザインパターンの振る舞い整合性を検証対象に含めつつ、名前空間の競合や特殊な解決規則を各サブモジュール内に局所化・カプセル化することで、システム全体に対して副作用を及ぼさない安全かつ決定論的なテストベッドを成立させています。
