本モジュール（`iryo.legacy.claims`）は、医療管理システムにおいて旧世代のレセプトコンピュータ（レセコン）やレガシーな医療費請求処理との後方互換性を担保・維持するための機能を提供するパッケージです。過去の仕様に基づく点数計算処理、請求・カルテ処理における一時的なデータ保持、ならびに旧規格に準拠した帳票・テキスト整形処理を集約しており、現行システムへの移行期間中におけるデータ照合や既存業務の円滑な継続を支える責務を担っています。

モジュール内では、経過措置加算を含む計算ロジックを提供する `PointTable` と、旧点数表を明示的に型付けするマーカークラス `OldTable` が点数算定の中核を担っています。これらの算定処理で扱われる単一のデータは、最小限の実装で設計されたジェネリックな `ChartCache` に一時保管されて処理フロー内を安全に受け渡されます。さらに、加工されたデータはサブモジュール `text` 内の `ReceiptFormatter` を通じて旧レセコン規格に準拠した文字列形式へと整形され、外部出力や連携データとして最終的に生成されるという一連の処理パイプラインを構成しています。

アーキテクチャ上の判断として、レガシー機能の局所化と予期せぬ改変の防止が重視されています。過去の計算ロジックを担うクラスには `@Deprecated` を付与して新規採用を抑制しつつ、クラス定義を `final` とすることで無秩序な継承を防いでいます。また、外部ライブラリへの依存を排除した疎結合かつ自己完結型の設計とし、Value HolderやFormatterといった軽量で責務が限定されたパターンを適用することで、将来的なレガシー機能の完全廃止や切り離しを容易にする保守性の高い構造が確立されています。
