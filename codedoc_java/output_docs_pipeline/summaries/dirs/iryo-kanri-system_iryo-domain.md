`iryo-kanri-system/iryo-domain` は、医療管理システムの中核を担うビジネスロジックとドメイン知識を一元管理するドメインモジュールです。本モジュールは、UIや永続化層、外部フレームワークなどの技術的詳細から完全に独立した純粋なドメインモデルの構築を目的としており、患者管理、診察予約、電子カルテ、医療費計算、病棟運用といった医療現場の基底業務に関する厳密なルールや知識を集約しています。

内部では、基盤となる共通監査・識別エンティティ（`Entity`、`AuditedEntity`）を土台とし、中核となる患者エンティティ（`Patient`）を中心に各サブドメインのコンポーネントが協調して動作します。診察予約（`Appointment`）や電子カルテ（`ChartEntry`、`ChartArchive`）などの診療系機能と、厳密な金銭計算を担う値オブジェクト（`Money`）や病棟管理機能が連携することで、患者の受け入れから診療プロセスの追跡、病棟配置、医療費算定に至る一連のライフサイクルが一貫性と自己完結性を持って処理されます。

アーキテクチャとしてはドメイン駆動設計（DDD）の原則が徹底されており、エンティティと値オブジェクトの厳格な分離や関心の分離（SoC）が図られています。また、スレッドセーフ性を高めるイミュータブルパターン、Static Factory MethodやPrototypeパターンによる安全なオブジェクト生成とライフサイクル管理、内部クラスを用いた詳細のカプセル化など、医療システムに求められる極めて高い完全性・監査性・保守性を担保する堅牢な設計判断が適用されています。
