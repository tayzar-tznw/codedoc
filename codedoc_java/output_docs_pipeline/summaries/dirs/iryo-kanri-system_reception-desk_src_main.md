本ディレクトリ（`iryo-kanri-system/reception-desk/src/main`）は、医療管理システムにおける受付端末アプリケーションのメインソースコードルートであり、配下の `java` ディレクトリに集約された各種コンポーネントを包括・管理する基盤として機能します。来院受付から会計、調剤連携、日次締め処理に至る受付デスクの一連の業務プロセスを実行可能なプログラムとしてまとめ上げ、エンドツーエンドの運用シナリオを安定して遂行できるようにすることを目的としています。

内部の構成においては、エントリーポイントである `Program.java` が合成ルート（Composition Root）として振る舞い、DIコンテナを利用してロギング、通知、データアクセスなどのインフラストラクチャサービス群を初期化・配線します。初期化されたサービス基盤のもとで、`CheckInFlow`（来院受付）、`AccountingFlow`（会計・領収書発行）、`PharmacyFlow`（調剤連携）といった `flows` 配下の業務フローコンポーネントが駆動し、ドメインロジック層や外部・旧システム連携層などのサブシステム間を調停・オーケストレーションして一貫した業務トランザクションを成立させています。

アーキテクチャ面では、Composition Root パターンと依存性の注入（DI）の徹底により具象クラス間の結合度を抑え、モジュール全体の保守性とテスト容易性を担保しています。また、各業務フローを Facade 的なコンポーネントとしてカプセル化することにより、純粋なドメイン知識と上位の業務オーケストレーションの責務を明確に分離し、医療受付特有の複雑な事前条件チェックや外部システム連携における整合性を局所的かつ堅牢に保証する設計を採用しています。
