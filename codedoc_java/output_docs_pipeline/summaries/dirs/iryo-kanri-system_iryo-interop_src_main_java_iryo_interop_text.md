`iryo.interop.text` パッケージは、医療管理システムにおける外部システム連携（interop）機能の一部として、連携対象データのテキスト整形およびフォーマット変換処理を担当するモジュールです。システム内部で扱われる各種ドメインデータを、外部連携仕様に適合した標準的なテキスト表現へ変換するための軽量なフォーマッター群を集約・提供することを目的としています。

本ディレクトリの主要コンポーネントである `ReceiptFormatter` は、領収データを受け取り、識別用プレフィックスを付与した外部連携用テキストへと整形する役割を担っています。外部ライブラリや他パッケージへの直接的な依存を持たず、Java標準機能のみで自己完結しているため、上位の連携処理サービスやオーケストレーション層から独立したステートレスなユーティリティとして呼び出されるシンプルな連携構造となっています。

アーキテクチャ上の判断として、単一責任の原則（SRP）に基づいた最小限のインターフェース設計が採用されています。また、クラスを `final` として宣言することで意図しない継承や振る舞いの改変を抑止し、堅牢で予測可能な動作を保証しています。依存関係を完全に排除した疎結合な設計により、外部連携仕様の変更時にも影響範囲を局所化でき、高い保守性と単体テスト容易性を確保しています。
