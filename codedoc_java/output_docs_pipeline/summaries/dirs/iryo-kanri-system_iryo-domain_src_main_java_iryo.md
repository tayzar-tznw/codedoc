本モジュール（`iryo` ルートパッケージ）は、医療管理システムにおける中核的な業務ルールおよびドメイン概念を表現・統括するドメイン層のエントリポイントです。外部のフレームワークやインフラストラクチャに依存しない純粋なJava仕様で構成されており、直下の `domain` パッケージを通じて、患者管理、診察予約、カルテ記録、金銭計算、ならびに病棟管理に至る医療現場の包括的なビジネスロジックとデータ構造を体系化しています。

内部のコンポーネントは、責務の明確な分離と高い整合性を保つよう密接に連携しています。基盤となる `Entity` および監査証跡を備えた `AuditedEntity` を継承する中心的存在の `Patient`（患者）に対し、`Appointment`（予約）や `ChartEntry`（カルテ記載）が参照関係を結び、さらに長期保管を担う `ChartArchive` がカルテのライフサイクルを支えます。これらに高精度な計算を提供する値オブジェクト `Money` や病棟単位のサブパッケージ（`north`、`south`）が組み合わさることで、診療から会計・病棟運用までの一連の業務フローがドメインモデル内で安全に完結します。

アーキテクチャ面ではドメイン駆動設計（DDD）の原則が徹底されており、エンティティと値オブジェクト（Value Object）の明確な峻別や、副作用を排除するイミュータブルパターンの採用が見られます。また、オブジェクトの安全な生成と複製を担う Static Factory Method や Prototype パターンの活用、内部クラスを用いた強力なカプセル化、関心の分離（SoC）を具現化したパッケージ構成など、変更に強く並行処理安全性の高い堅牢なオブジェクト指向設計が確立されています。
