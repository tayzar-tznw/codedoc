本モジュール（`iryo-kanri-system/reception-desk/src/main/java/iryo`）は、医療管理システムにおける受付端末アプリケーションの最上位ルートパッケージとして機能し、配下の `reception` パッケージを通じてシステム全体の初期化および各種受付業務シナリオのライフサイクルを統括・実行することを目的としています。実質的な実装を担う `reception` サブシステムを内包することで、受付デスクで求められる日常的な来院受付から会計、調剤連携、締め処理に至る一連の運用プロセスを束ねるエントリーポイントの役割を果たしています。

内部のコンポーネント連携において、中心となる `Program.java` が合成ルート（Composition Root）として振る舞い、基盤層のDIコンテナを活用してロギング、通知、データアクセスなどの共有インフラストラクチャサービスを構成・初期化します。生成されたサービスコンテキストを基盤として、`Program` は `flows` 配下の各業務フローコンポーネント（来院受付を担う `CheckInFlow`、請求・領収書発行を担う `AccountingFlow`、調剤連携の `PharmacyFlow` など）を順次起動し、ドメイン層や外部・旧システム連携層といった複数の独立したサブシステムと対話させながらエンドツーエンドの業務手順をオーケストレーションします。

アーキテクチャ面では、Composition Root パターンおよび依存性の注入（DI）を採用することで、具象実装間の結合度を最小限に抑え、モジュール全体の保守性とテスト容易性を向上させています。また、各業務フローを状態を持たない Facade 的なユーティリティとしてカプセル化し、純粋なドメインロジックと上位の業務オーケストレーションを明確に分離する設計判断が下されています。これにより、複雑な医療受付業務の事前条件検証や外部システムとの整合性担保をフロー層に集約し、堅牢で拡張性の高いシステム構造を実現しています。
