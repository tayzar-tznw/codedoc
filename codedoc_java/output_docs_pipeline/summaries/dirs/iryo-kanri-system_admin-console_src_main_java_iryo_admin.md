本ディレクトリ（`iryo.admin`）は、医療管理システムにおける管理コンソールアプリケーション（admin-console）の中核ロジックを担うモジュールです。管理者向けの日次バッチ処理や週次集計レポートの出力を統括・実行することを全体的な目的としており、システム運用に必要な定期タスクを一括して処理する基盤を提供します。

内部の主要コンポーネントは密接に連携しており、システム全体のエントリーポイントとなる `Program` クラスが処理フローを統括します。`Program` の `main` メソッドから、日次点検プロセスを担当する `DailyBatch` と週次の生体データおよび収益集計を担当する `ReportDigest` の各実行メソッド（`run()`）が順次呼び出される構成です。これら各処理は、調剤層（`iryo.pharmacy`）の検証・計算機能、ドメイン層（`iryo.domain`）の金額処理モデル、およびレポート出力共通部品（`iryo.reporting`）と連携し、業務機能のオーケストレーションを行っています。

アーキテクチャ上の判断として、本パッケージ内の全クラスは `final` 修飾子とプライベートコンストラクタによる「ユーティリティクラスパターン」で統一されています。インスタンス化を抑止したステートレスな静的メソッドによる実行モデルを採用することで、コンソール実行やバッチ処理の起動をシンプルかつ安全に実現し、管理層が各業務ドメインの部品を横断的に統合・再利用する設計となっています。
