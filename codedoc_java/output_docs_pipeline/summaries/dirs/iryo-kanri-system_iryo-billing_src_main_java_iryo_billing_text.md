`iryo.billing.text` モジュールは、医療会計システムにおける請求および会計処理の出力層として、各種領収書や帳票出力に関わるテキストの整形・標準化を担う軽量なユーティリティ/プレゼンテーション層です。業務ロジックから表示用の文字列生成処理を明確に分離し、一貫したフォーマットルールをカプセル化することを主な目的としています。

現行の実装では単一のコンポーネントである `ReceiptFormatter` が中心的な責務を担っており、受け取った領収書項目オブジェクトに対して所定の接頭辞を付与した標準形式の文字列を生成します。アーキテクチャ上の判断として、本クラスは状態を持たないステートレスな設計が徹底されており、スレッドセーフな利用が保証されています。また、サードパーティ製ライブラリや他パッケージへの依存を排除し、Java標準クラスのみで自己完結させることで、高い凝集度と疎結合性を維持しています。

設計パターンとしては、出力フォーマットの関心事を切り離す Formatter パターンを採用しており、クラスを `final` として継承を禁止することで振る舞いの無秩序な変更を抑止しています。これにより、会計データの表示仕様変更が発生した際にも業務コア層への影響を及ぼすことなく、テキスト整形ロジックを局所的かつ安全に変更・拡張できる構造を実現しています。
