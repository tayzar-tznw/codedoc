`iryo.domain` モジュールは、医療管理システムにおける中核的なビジネスルールおよびドメイン概念を表現・カプセル化するドメイン層のルートパッケージです。外部のフレームワークやインフラストラクチャに一切依存せず、純粋なJava標準仕様のみで構成されています。患者管理、診察予約、カルテ記載、金銭計算、さらには物理的区画を表す病棟サブパッケージ（`north`、`south`）に至るまで、医療現場の業務ロジックを構成する基本的なデータ構造と振る舞いを定義しています。

内部のコンポーネントは、責務の分離と整合性を考慮して密接に連携しています。基底クラスである `Entity` から監査ログ機能を備えた `AuditedEntity` を経て、具象クラス `Patient` に至る明確な継承ツリーが形成されており、識別性と変更履歴管理を統一しています。この患者モデルを中心に、`Appointment`（予約情報）や `ChartEntry`（カルテ記載）が患者IDを介して参照関係を結び、カルテの長期保管や保守処理を `ChartArchive` が担います。加えて、汎用的な高精度計算を提供する値オブジェクト `Money` が組み合わさることで、診療から会計までのドメイン操作を安全に完結させる構造となっています。

本レイヤではドメイン駆動設計（DDD）の原則が強く意識されており、エンティティと値オブジェクト（Value Object）の峻別や、状態の副作用を排除するイミュータブル（不変）パターンが徹底されています。また、Static Factory Method パターンや Prototype パターンによる安全なオブジェクト生成・複製、ネストクラスを用いた高いカプセル化（`ChartArchive`）、病棟単位でのサブパッケージ分割による関心の分離（SoC）など、堅牢性と並行処理安全性を両立する高度なオブジェクト指向設計が採用されています。
