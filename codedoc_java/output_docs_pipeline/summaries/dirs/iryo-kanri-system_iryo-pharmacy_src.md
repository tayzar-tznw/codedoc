本ディレクトリ（`iryo-pharmacy/src`）は、医療管理システムにおける薬局・調剤モジュールのソースコードを統括するルートディレクトリです。その主たる目的は、調剤業務におけるビジネスルール、計算エンジン、およびドメインデータモデルの実装を集約・管理し、システム全体に安全で一貫性のある調剤ドメイン機能を提供することにあります。処方指示の受け入れから適正投与量の算出、点数・金銭の費用計算、監査ログの保持に至るまで、調剤ワークフローに必要な中核ロジックを包括的にカプセル化しています。

配下のプロダクションコード群は、調剤パイプラインの各フェーズに応じて密接に連携します。入力された処方データは `Validator` により構文や業務制約の厳格な検証を受け、妥当性が保証されたデータをもとに `DoseCalculator` が患者の体重等に応じた安全な投与量を算出します。続いて `PointMath` が薬価点数と換算レートに基づく費用計算を実行し、計算された金銭情報は不変値オブジェクトである `Money` を通じて安全に取り扱われます。これら一連の処理で発生するイベントは `Logger` により追跡・蓄積され、業務監査とトレーサビリティを確立します。

アーキテクチャ上の設計判断として、外部フレームワークへの依存を排した自己完結型のクリーンな設計が徹底されています。検証や計算を担うコンポーネントにはステートレスなユーティリティクラスを採用し、ドメインモデルには値オブジェクトパターンによる不変性の担保や防御的コピーを適用することで副作用を排除しています。これにより、医療システムに求められる極めて高い正確性と堅牢性を担保するとともに、テスト容易性に優れた保守性の高い構造を実現しています。
