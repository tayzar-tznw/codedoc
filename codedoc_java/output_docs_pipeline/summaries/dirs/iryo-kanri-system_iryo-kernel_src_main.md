本ディレクトリ（iryo-kanri-system/iryo-kernel/src/main）は、医療管理システム全体の中核を担う「iryo-kernel」モジュールのメインソースコード領域であり、Java標準APIのみを用いて構築された共通基盤を提供します。上位の業務ロジックやフレームワーク実装から完全に独立したアーキテクチャ境界を形成し、システム共通の依存性注入（DI）基盤、ドメインポリシーの抽象仕様、および堅牢な汎用ユーティリティを集約することで、システム全体の高い移植性、保守性、テスタビリティを担保することを目的としています。

配下の主要コンポーネントは、軽量DI機能を中心に密接に連携しています。基幹となる `ServiceCollection` と `ServiceProvider` がコンポーネントのライフサイクル管理とコンストラクタインジェクションを通じた依存解決を司り、その実行基盤上で `PaymentPolicy`（診療報酬等の算定ルール）に基づくドメイン戦略や `Notifier` による通知機構が動的に協調動作します。さらに、横断的関心事として入力値検証を担う `Guard` やロギング機能が組み込まれ、コンポーネント間の安全なデータ授受と安定した実行環境を確立しています。

アーキテクチャ面では、上位層が具象実装ではなく抽象インターフェースに依存する「依存性逆転の原則（DIP）」と、業務ルールの差し替えを容易にする「Strategyパターン」が徹底されています。また、Fluent APIによる宣言的なサービス登録インターフェースの提供、早期リターンを促すガード節の標準化、リフレクションを活用した疎結合な依存解決、さらには後方互換性を保つAdapterやFacadeパターンの採用など、外部ライブラリ非依存でありながらエンタープライズ規模の拡張性と整合性を両立する設計判断が一貫して適用されています。
