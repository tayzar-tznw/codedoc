`iryo-kanri-system/patient-portal` は、医療管理システムにおいて患者が外部ネットワークから安全に利用できるWebインターフェースおよびAPI基盤を提供するモジュールです。患者向けの診療予約管理、自己負担額を含む請求情報の照会、各種手続き完了通知などのセルフサービス機能を集約し、エンドユーザーからのリクエスト受付からバックエンド連携、レスポンス生成に至るエンドツーエンドの処理を実現することを全体的な目的としています。

本モジュールの中核実装は `src` ディレクトリ配下に体系化されており、主要コンポーネントである `PortalServer` がクライアントからのHTTP要求を一括してハンドリングします。受け取ったリクエストは、Facadeパターンを介して予約管理や請求計算、通知基盤といった業務ドメインと連携し、複雑なバックエンドロジックを隠蔽しながら疎結合に処理をオーケストレーションします。一方で、旧来の画面生成を担っていたJSP等のプレゼンテーション資産は直接参照から切り離され、将来的な完全移行を見据えた参照用リソースとして安全に隔離・共存しています。

アーキテクチャ上の判断として、重量級フレームワークへの依存を避けてJava標準のHTTPサーバー機能を活用することで、ランタイムの軽量化と高い可搬性を確立しています。さらに、Facadeパターンによる業務ドメインの抽象化と、レガシー資産の段階的な移行を許容する構造設計を組み合わせることで、システムの拡張性、保守性、および近代化における安全性を高度に両立させています。
