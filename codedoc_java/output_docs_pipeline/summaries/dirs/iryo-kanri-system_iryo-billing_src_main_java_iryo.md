本ディレクトリ（`iryo`）は、「iryo-billing」モジュールにおける最上位のJavaルートパッケージであり、医療管理システムの中核を成す診療報酬請求および窓口会計処理のドメイン機能を提供することを目的としています。直下には子ファイルを持たず、業務ロジックの関心事ごとに整理されたサブパッケージ（`iryo.billing`）を束ねるネームスペースとして機能し、公的医療保険制度に準拠した点数計算、金額換算、各種入力バリデーション、帳票出力テキストの生成といった請求ドメイン全体の責務を集約・体系化しています。

本配下の各コンポーネントは、請求処理パイプラインとして有機的に連携しています。`Validator` による保険証情報の入力検証を起点とし、`FeeCalculator` が診療報酬点数の算出や各種割引ロジックの適用を行い、`PointMath` が計算された点数を法定レート（1点＝10円）と四捨五入ルールに基づいて確定金額へと換算します。最終的に算出された請求データは、サブパッケージ内の `ReceiptFormatter` に引き渡され、領収書や請求書としての標準化された帳票形式に整形・出力されます。

アーキテクチャの観点では、Utility Class、Validator、Formatter といった各種設計パターンを採用し、各機能の責務分離と高い凝集度を実現しています。すべてのコンポーネントでステートレス設計とクラスの `final` 化を徹底することで、並行処理環境における完全なスレッドセーフ性と不変性を担保しています。また、サードパーティライブラリへの依存を排除し Java 標準仕様のみで自己完結させることで、医療保険制度や点数体系の改定に対しても柔軟かつ安全に対応できる堅牢な基盤を確立しています。
