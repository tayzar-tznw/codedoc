本ディレクトリ（`iryo.scheduling`）は、医療管理システムにおける予約管理（スケジューリング）のコアロジックを担うモジュールです。システム内における予約情報の登録・状態管理と、予約確定時などの患者向け通知処理という、スケジューリング機能に不可欠な中核的責務を果たすコンポーネントを提供しています。

モジュール内では、予約データの管理を担う`AppointmentBook`と、通知手段を提供する`SmsNotifier`が定義されています。`AppointmentBook`はドメインモデルである`Appointment`を取りまとめてインメモリで保持し、新規予約の登録や患者ごとの予約状況の集計・追跡を行います。一方、`SmsNotifier`はコア基盤で定義された通知インターフェースの実装として機能し、予約手続きに伴う患者へのメッセージ送信処理を具体化することで、予約業務フロー全体の完結を支えています。

アーキテクチャの観点では、関心の分離と疎結合化を意図した設計パターンが採用されています。`AppointmentBook`にはファーストクラスコレクションおよび簡易インメモリ・リポジトリパターンが適用されており、コレクション操作を安全に隠蔽して予約データの整合性を担保しています。また、`SmsNotifier`は`iryo.kernel.Notifier`に対するStrategyパターンの具象クラスとして実装されており、共通インターフェースに依存させることで、将来的な通知手段の追加や変更に強い柔軟な構造を実現しています。
