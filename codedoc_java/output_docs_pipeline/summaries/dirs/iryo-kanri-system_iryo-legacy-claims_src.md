本ディレクトリ（`iryo-legacy-claims/src`）は、医療管理システムにおける旧世代レセプトコンピュータ（レセコン）仕様および過去の診療報酬請求ロジックを統合・管理するためのソースコードルートです。新旧システムの移行期において既存業務の継続性やデータ整合性を確保しつつ、旧仕様固有の複雑なビジネスルールが現行のコアドメインに侵入することを防ぐ「防腐層（Anti-Corruption Layer）」としての責務を担っています。

内部構造は配下の `main` ディレクトリを中心に、旧仕様に特化した一連の自己完結型処理パイプラインとして設計されています。過去の点数表や経過措置ルールをカプセル化した算定コンポーネント群（`OldTable`、`PointTable`）が請求計算を行い、その結果を軽量なキャッシュ機構（`ChartCache`）を介して安全に伝達します。最終的に専用のフォーマット変換モジュール（`ReceiptFormatter`）が旧レセコン規格に準拠したテキスト形式へ整形・出力することで、算定から帳票生成に至る一貫したデータ処理連携を実現しています。

アーキテクチャ面では、将来的なレガシー機能の安全な廃止（サンセット）を容易にすることを重視した設計判断がなされています。各コンポーネントは外部依存を最小限に抑えた責務分離パターンで実装されており、クラスへの `@Deprecated` アノテーション付与や `final` 修飾による継承防止といった防御的プログラミングを徹底しています。これにより、新機能開発からの意図しない依存を防ぎ、モジュール全体の高い独立性と安全性を確立しています。
