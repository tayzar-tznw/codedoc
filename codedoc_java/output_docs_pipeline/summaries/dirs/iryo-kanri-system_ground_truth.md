`iryo-kanri-system/ground_truth` ディレクトリは、医療管理システムにおける調剤や請求などの複雑な業務モジュール境界を対象に、Java言語仕様に準拠した型推論、オーバーロード解決、インポート規則、スコープ遮蔽などのコンパイラセマンティクスを実証・評価するためのグラウンドトゥルース（正解データ）検証モジュールです。本番コードに手を加えることなく、静的な名前解決と実行時ディスパッチの挙動が仕様通りに整合しているかを決定論的かつ高精度に検証・保証することを全体的な目的としています。

本ディレクトリの核となる `SemanticProbe` においては、全体の実行を統括するオーケストレーター `probe.Program` を起点とし、静的インポートの隠蔽を検証する `shadow` や、業務コンテキストに応じた名前解決の差異を追跡する `xpr`（`AdminSide`、`ReceptionSide`）などの特化型プローブ群が有機的に連携して動作します。各コンポーネントはリフレクションや `SerializedLambda` を用いたメタプログラミング技術を活用し、コンパイル時に静的バインドされたシグネチャ記述子を実行時に動的抽出・照合することで、コンパイラの振る舞いに対する監査と妥当性確認をシームレスに行う連携体制を構築しています。

アーキテクチャ設計においては、検証の再現性と信頼性を最優先事項とし、可変状態や副作用の徹底的な排除が徹底されています。意図的な名前空間の競合や特殊なインポート規則が外部に漏洩・干渉しないよう、各検証ロジックには `final` 修飾や非公開コンストラクタを用いたユーティリティクラスパターンを適用し、サブモジュール単位で厳密なカプセル化を実施しています。これにストラテジーパターンなどを組み合わせることで、システム全体の安定性を損なうことなく高度な言語仕様検証を柔軟に追加・実行できる、堅牢かつ保守性の高いテストベッド基盤を実現しています。
