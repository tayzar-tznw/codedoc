本ディレクトリ（`src/main/java`）は、医療管理システムにおけるグラウンドトゥルース検証ツール「SemanticProbe」のJavaソースルートです。製品コードを変更することなく、Java言語仕様に準拠した型推論、オーバーロード解決、インポート規則、スコープ遮蔽（シャドウイング）の正当性を実行時に決定論的に実証するための検証基盤を提供します。調剤系や請求系といった複雑な業務モジュールの境界条件において、コンパイラによる静的型解決から実行時の動的ディスパッチに至るセマンティクスが仕様通りに機能するかを網羅的に検証することを目的としています。

配下の `iryo` パッケージでは、中核エントリポイントである `probe.Program` を起点として特化された各検証サブモジュールが有機的に連携・実行されます。静的インポートによるメソッド隠蔽ルールを検証する `shadow` パッケージや、同一コードがインポート先の相違によって挙動を分岐させる様子を検証する `xpr` パッケージ（`AdminSide`、`ReceptionSide`）を順次駆動し、整合性を照合します。さらに、`SerializedLambda` とリフレクションを活用してコンパイラがバインドしたシグネチャ記述子を動的に解析・照合することで、精緻な仕様検証を実現しています。

アーキテクチャ上の設計としては、検証結果から可変状態などの外部要因や副作用を徹底して排除するため、各プローブクラスに `final` 宣言および非公開コンストラクタを適用するユーティリティクラスパターンが徹底されています。また、DIコンテナやストラテジー、ファクトリといったデザインパターンの振る舞い検証を取り入れつつ、名前空間の競合や特殊な解決規則を各サブモジュール内に局所化・カプセル化することで、システム全体に対して安全かつ再現性の高い決定論的テストベッドを確立しています。
