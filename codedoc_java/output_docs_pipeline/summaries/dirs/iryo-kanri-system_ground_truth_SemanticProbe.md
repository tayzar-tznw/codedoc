`SemanticProbe` は、医療管理システムにおける調剤や請求といった複雑な業務モジュールの境界において、Java言語仕様に準拠した型推論、オーバーロード解決、インポート規則、およびスコープ遮蔽（シャドウイング）などのコンパイラセマンティクスを実証・評価するためのグラウンドトゥルース検証フレームワークです。製品コードに改変を加えることなく、静的な名前解決と実行時ディスパッチの挙動が仕様通りに整合しているかを決定論的に検証することを目的としています。

本モジュールの中核となる `src` ソースツリーでは、全体の実行を統括するオーケストレーター `probe.Program` を起点とし、静的インポートの隠蔽を検証する `shadow` や、コンテキストに応じた名前解決の差異を追跡する `xpr`（`AdminSide`、`ReceptionSide`）などの特化型プローブ群が協調して動作します。各コンポーネントはリフレクションや `SerializedLambda` などのメタプログラミング技術を活用し、コンパイル時に静的バインドされたシグネチャ記述子を実行時に動的抽出・照合することで、コンパイラの振る舞いを高精度に監査・検証する連携体制を構築しています。

アーキテクチャ設計においては、検証の再現性と信頼性を担保するため、可変状態や副作用の徹底的な排除が図られています。各検証ロジックには `final` 修飾や非公開コンストラクタを用いたユーティリティクラスパターンが適用され、意図的な名前空間の競合や特殊なインポート規則をサブモジュール単位で厳密にカプセル化しています。ストラテジーパターンなどを効果的に組み合わせることで、システム全体の安定性を損なうことなく高度な言語仕様検証を可能にする、安全かつ拡張性に優れたテストベッドを実現しています。
