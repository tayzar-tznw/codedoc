本モジュール（`iryo-legacy-claims`）は、医療管理システムにおいて旧世代レセプトコンピュータ仕様および過去の診療報酬請求ロジックを集約・管理するための独立したコンポーネントです。新旧システムの移行期において既存業務の継続性とデータ整合性を担保しつつ、旧仕様特有の複雑なビジネスルールが現行のコアドメインに侵入・汚染することを防止する「防腐層（Anti-Corruption Layer）」としての責務を担っています。

内部の `src` ディレクトリ配下では、自己完結型の処理パイプラインが構築されています。過去の点数表や経過措置ルールをカプセル化した算定コンポーネント群（`OldTable`、`PointTable`）が請求計算を実行し、その処理結果を軽量なキャッシュ機構（`ChartCache`）を介して受け渡します。最終的に専用のフォーマット変換モジュール（`ReceiptFormatter`）が旧レセコン規格に準拠したテキスト形式へ整形・出力することで、算定から帳票生成に至る一連の請求処理がシームレスに連携しています。

アーキテクチャ面では、将来的なレガシー機能の安全な段階的廃止（サンセット）を前提とした設計判断が徹底されています。各コンポーネントは外部依存を最小限に抑えた責務分離パターンで構成され、クラスへの `@Deprecated` 付与や `final` 修飾による継承防止などの防御的プログラミングを採用しています。これにより、新規機能開発からの意図しない依存を物理的・構造的に遮断し、高凝集かつ低結合なモジュール独立性を確立しています。
