`iryo.domain.south` ディレクトリは、医療管理システムにおける「南病棟」に特化したビジネス概念やロケーション情報をカプセル化して表現することを目的としたドメインモジュールです。本パッケージは、病院内の物理的・機能的な区画としての病棟モデルを提供し、システム内の案内機能や病棟特定に関するドメインロジックの基盤を担っています。

現時点での主要コンポーネントは `Ward.java` のみであり、南病棟の識別情報を返却する役割に特化して単体で完結しています。このクラスは `final` 修飾子により継承が制限され、外部依存を一切持たない軽量で不変性の高いValue Object的な設計が採用されています。状態を変更させない純粋なモデルとすることで、スレッドセーフかつ副作用のない安全な振る舞いを実現しています。

アーキテクチャ上の観点では、方角や病棟ごとにパッケージを分離することでモジュール性を高め、関心の分離（SoC）を図る設計判断が見られます。本モジュール内のコンポーネントは、上位層や他の病棟パッケージ（東西北など）とインターフェースを介して疎結合に連携し、ポリモーフィズムやStrategyパターンに基づく統一的な病棟処理を実現する具象実装として位置付けられています。
