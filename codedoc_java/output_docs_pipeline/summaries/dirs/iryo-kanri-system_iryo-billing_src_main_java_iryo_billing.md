`iryo.billing` モジュールは、医療管理システムにおける診療報酬請求および窓口会計の核となるドメインロジックを提供するパッケージです。公的医療保険制度に基づいた診療報酬点数の算出、点数から日本円への換算および端数丸め処理、保険証情報の入力検証、さらには請求書や領収書の発行に向けたテキスト整形に至るまで、請求処理に関わる一連の責務を集約して担っています。

本モジュールを構成するコンポーネントは、請求処理パイプラインの各段階において明確に役割を分担して連携します。まず `Validator` が保険証記号番号の形式妥当性を検証し、`FeeCalculator` が点数計算や条件に応じた割引ロジック、各種請求関連メッセージの生成を実行します。さらに `PointMath` が計算された点数を1点＝10円のレートで金額に換算し、10円未満の端数四捨五入を行うことで最終的な請求額を確定させます。得られた請求データは、サブモジュールである `text` パッケージの `ReceiptFormatter` に渡され、標準化された帳票・領収書用テキストとして整形・出力されます。

アーキテクチャの観点では、各コンポーネントが状態を保持しないステートレスな設計を徹底しており、`final` 修飾子による継承禁止と併せて優れたスレッドセーフ性と不変性を実現しています。Utility Class パターン、Validator パターン、Formatter パターンを採用して関心事を分離し、サードパーティ製ライブラリへの依存を排除して Java 標準ライブラリのみで自己完結させています。これにより、制度改定に伴う計算規則の変更や帳票書式の変更に対しても、業務コアロジックへの影響を最小限に抑えられる高凝集・疎結合な構造を確立しています。
