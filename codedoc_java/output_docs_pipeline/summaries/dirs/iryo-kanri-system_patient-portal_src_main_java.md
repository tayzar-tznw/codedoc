本ディレクトリ（`iryo-kanri-system/patient-portal/src/main/java`）は、患者向けポータルサブシステムのJavaソースコードのルートディレクトリであり、患者が外部からシステムへアクセスするためのWebインターフェースおよびAPI機能の実装を統括することを目的としています。配下の`iryo`パッケージを中心に、クライアントからのHTTPリクエストの受付から各種業務ロジックの呼び出し、レスポンス返却に至る一連のエンドツーエンド処理を管理し、予約管理や料金照会といった患者向けサービスのエントリーポイントを提供します。

アーキテクチャの核となるコンポーネントは、`iryo.portal`パッケージ内に配置された`PortalServer`です。本コンポーネントがコントローラーおよびオーケストレーターとして機能し、HTTPエンドポイントを通じて受信した患者からのリクエストをハンドリングします。受信した要求に基づき、スケジュールを管理する予約サービス、診療報酬点数から自己負担額を算出する請求サービス、および完了通知を発行する通知基盤といった各種ドメインサービスを連携・統合し、クライアントへ一貫した処理結果を返却する役割を担っています。

設計面においては、複数の独立した業務ドメイン（予約・請求・通知）に対するアクセス窓口を集約するFacadeパターンが採用されており、外部クライアントに対してバックエンドの複雑性を隠蔽しています。また、重量級フレームワークを排してJava標準のHTTPサーバー機能を採用することで、ランタイムの軽量化と可搬性を向上させつつ、インターフェース設計を活用して各ドメイン機能間の疎結合性を維持する堅牢なアーキテクチャを実現しています。
