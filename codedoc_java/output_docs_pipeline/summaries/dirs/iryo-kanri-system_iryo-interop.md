`iryo-interop` モジュールは、医療管理システムにおいて外部機関や他システムとの安全かつ正確なデータ連携・相互運用性（インターオペラビリティ）を一元的に担う基底コンポーネントです。提出用データの生成、各種形式（CSVやXML等）へのフォーマット変換、およびシステム間のデータ整合性を担保するための識別子標準化・正規化処理といった外部連携に不可欠な基幹ロジックを集約・提供しています。

モジュール内部では、出力契約を定義する `Exporter` インターフェースを核とし、データ整形・検証を担うコンポーネント群がパイプライン状に連携しています。具体的には、患者IDの表記揺れを統一・検証する `PatientIdKit` や、医療報酬請求データを構造化する `ReceiptFormatter` が入力データの正規化と整形を行い、その結果を各形式に応じた具象エクスポーターへ受け渡すことで、一貫性のある外部提出用データをシームレスに生成します。

アーキテクチャ面では、出力形式の追加や仕様変更に柔軟に対応できるようStrategyパターンを採用し、オープン・クローズドの原則（OCP）に基づいた疎結合な設計を実現しています。さらに、クラスの不変性（イミュータビリティ）の徹底やインスタンス化の抑止といった防御的プログラミングを適用するとともに、サードパーティライブラリへの依存を排除したピュアなJava実装を維持することで、高い堅牢性、保守性、およびテスト容易性を確保しています。
