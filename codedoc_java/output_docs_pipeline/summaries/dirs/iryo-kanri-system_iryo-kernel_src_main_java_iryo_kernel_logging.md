本モジュールは、診療業務システムにおける基盤層（`iryo-kernel`）の一部として、システム全体で統一されたログ記録および診断・追跡機能を提供することを目的としています。主要コンポーネントである `Logger` クラスが中核を担い、システム内で発生するイベントメッセージや例外情報を、発生元の所有者コンテキスト（`owner`）とともにメモリ上で安全に収集・管理する責務を果たします。

内部構造としては単一クラスで完結しており、オーバーロードされた複数の `log` メソッドを介して通常メッセージ、重要度付きメッセージ、例外スタックトレースを規格化されたフォーマットで内部リストに蓄積します。蓄積されたログ行は `lines()` メソッドを通じて外部に提供され、また将来的な永続化処理の拡張を見据えた `flush()` メソッドを備えることで、呼び出し元モジュールに対してシンプルかつ一貫したインターフェースを提供しています。

アーキテクチャ上の判断として、外部ライブラリに一切依存せず `java.util` の標準コレクションのみを採用することで、カーネル領域に求められる極めて低い結合度と高い移植性を維持しています。設計パターンとしては、読み取り専用リスト（`Collections.unmodifiableList`）の返却による厳格なカプセル化とイミュータビリティの保護が徹底されているほか、ログの出力先や永続化戦略を将来的に差し替え・拡張可能な構造とすることで、堅牢性と拡張性を両立させています。
