`iryo-kanri-system/reception-desk` は、医療管理システムにおいて来院受付、会計・領収書発行、調剤連携、日次締め処理などの窓口業務を一貫して支援する受付端末アプリケーションのルートモジュールです。医療現場におけるフロントデスク業務のエンドツーエンドなプロセスを統合的に管理・実行し、安定かつ確実な日常運用を実現することを目的としています。

本モジュールの中核となる `src` ディレクトリ内では、エントリーポイントである `Program.java` がシステムの起点としてDIコンテナを用いた初期化と依存関係の解決を一括して行い、ロギングやデータアクセスなどの基盤層を立ち上げます。その上で稼働する `CheckInFlow`、`AccountingFlow`、`PharmacyFlow` などの主要フローコンポーネントが、ドメインロジックや外部・レガシーシステム連携層を適切に調停・オーケストレーションすることで、各業務トランザクションを円滑に連携・成立させています。

アーキテクチャ面では、Composition Root パターンと依存性の注入（DI）を採用して具象クラス間の結合度を最小限に抑え、保守性とテスト容易性を高めています。また、各業務フローを Facade 的なコンポーネントとしてカプセル化することで、純粋なドメインルールと上位の業務進行責務を明確に分離し、医療受付特有の厳密な事前条件チェックや外部連携時のデータ整合性を堅牢に担保する設計となっています。
