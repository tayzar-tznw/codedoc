本ディレクトリ（`iryo-kanri-system/iryo-scheduling/src`）は、医療管理システムにおける予約管理（スケジューリング）機能のソースコード全体を統括するルート階層です。患者の診療予約の受付から状態追跡、確定、そして患者への通知完了に至る一連のスケジューリング業務の中核ビジネスロジックを集約し、予約処理の信頼性とデータ整合性を一貫して担保することを目的としています。

内部では、予約ドメインモデルと外部連携コンポーネントが明確な責務分担のもとで密接に連携しています。中核コンポーネントである`AppointmentBook`が予約エンティティの集約や業務ルールの検証、予約状態のライフサイクル管理を行い、予約確定などの主要な状態遷移に連動して`SmsNotifier`が患者へのメッセージ送信処理をトリガーします。これにより、スケジューリングの業務フローと患者コミュニケーションがシームレスに同期して動作する仕組みを構築しています。

アーキテクチャの観点では、関心の分離と高い保守性・拡張性を意図したパターンが随所に適用されています。`AppointmentBook`にファーストクラスコレクションやインメモリ・リポジトリパターンを採用することでドメインの整合性を強固にカプセル化しつつ、通知機能にはStrategyパターンを適用して具体的な通信実装を抽象インターフェースから分離しています。これにより、ドメインの中核ロジックに影響を与えることなく、将来的な永続化層の刷新や新たな通知チャネルの追加に柔軟に対応できる疎結合なアーキテクチャを実現しています。
