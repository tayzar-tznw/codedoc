`iryo.data` モジュールは、医療管理システムにおけるデータアクセス層の抽象化およびインメモリデータ管理の基盤を提供する役割を担っています。ドメイン層と具体的な永続化技術を分離し、患者情報をはじめとする医療データの効率的かつ安全な取得・保持を実現するためのコンポーネント群を集約しています。

モジュール内部では、汎用的なデータ取得規約を定める `Repository<T>` インターフェースを中心に、その具象クラスである `SqlPatientRepository` がドメインモデル（`Patient`）と連携してデータアクセス処理を具体化しています。このリポジトリの生成責務は `RepositoryFactory` が担い、ロギング機能等の依存関係を注入した形で利用側へ提供します。また、カルテ情報などの高速な読み出しを可能にするジェネリックな `ChartCache` や、リフレクションを利用して動的なオブジェクト生成を支援する `Registry` ユーティリティが併設され、データアクセスとインスタンス管理の双方からシステム全体を支えています。

アーキテクチャ面では、ドメイン駆動設計に基づく「Repositoryパターン」の適用により、ビジネスロジックが永続化実装に依存しない疎結合な構造を確立しています。加えて、「Static Factoryパターン」によるインスタンス生成のカプセル化や、「Cacheパターン」によるパフォーマンスの最適化、コンストラクタ経由の依存性の注入（DI）が実践されています。Java標準機能を中心に構成することで外部依存を最小限に抑え、テスタビリティと再利用性に優れた堅牢なデータ層を実現しています。
