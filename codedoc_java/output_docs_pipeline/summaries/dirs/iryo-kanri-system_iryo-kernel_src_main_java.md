本ディレクトリ（`iryo-kanri-system/iryo-kernel/src/main/java`）は、医療管理システム全体を支える中核基盤モジュール「iryo-kernel」のJavaソースコードのルートであり、外部ライブラリに依存せずJava標準APIのみで構築された共通基盤層です。上位の業務ロジックやアプリケーション層から完全に独立した形で、システム全体の標準規約、ドメインポリシーの抽象定義、および汎用的な実行インフラ機能を提供し、システムの移植性と高水準な整合性を担保することを目的としています。

配下の `iryo.kernel` パッケージを中心として、軽量な依存性注入（DI）機構、ドメイン戦略、堅牢化ユーティリティが密接に連携しています。基盤となる `ServiceCollection` と `ServiceProvider` がコンポーネントのライフタイム管理およびコンストラクタインジェクションを通じた依存解決を司り、その実行基盤上で `Notifier` を介した通知連携や、`PaymentPolicy`（`StandardPolicy` や `UrgentPolicy` など）に基づく診療手数料算定ルールが動的に協調動作します。さらに、共通的な入力値検証を担う `Guard` やロギング機能が横断的関心事として組み込まれ、システム全体の安定稼働を支えています。

アーキテクチャ面では、上位モジュールが具象実装ではなく抽象インターフェースに依存する「依存性逆転の原則（DIP）」と、業務ルールの動的な差し替えを容易にする「Strategyパターン」が徹底されています。また、Fluent APIによる宣言的なサービス登録、早期リターンを促進するガード節、リフレクションを活用した柔軟な依存解決、さらには後方互換性を担保するAdapterおよびFacadeパターンの適用など、拡張性とテスタビリティ、保守性を高度に両立させる設計判断が一貫して下されています。
