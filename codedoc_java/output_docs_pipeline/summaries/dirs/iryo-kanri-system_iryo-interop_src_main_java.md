本ディレクトリは、医療管理システムにおける外部システム連携（相互運用性）を担うJavaソースコードのルートディレクトリです。外部機関や他システムとの安全かつ高精度なデータ交換を実現するため、提出用データの生成、各種形式へのフォーマット変換、およびデータ照合に不可欠な識別子の標準化・正規化処理を集約・カプセル化することを目的としています。

配下の `iryo` パッケージ（主に `interop` サブモジュール）では、共通インターフェースである `Exporter` を中心に、CSVやXML形式に対応した具象エクスポーター群が柔軟な出力パイプラインを形成しています。これらは、患者IDの表記揺れを解消する `PatientIdKit` や、レセプト等の帳票整形を担う `ReceiptFormatter` などのフォーマッター群と密接に相互作用し、データの正規化・整形からファイル出力までの一連の処理を一貫して実行します。

設計面では、出力形式の拡張や切り替えを容易にするStrategyパターンを採用することで、オープン・クローズドの原則（OCP）を順守しています。また、クラスの `final` 宣言やユーティリティクラスのインスタンス化抑止といった防御的プログラミングを徹底し、外部ライブラリへの依存を抑えた純粋なJava実装とすることで、高い保守性、テスト容易性、および堅牢な可搬性を備えた疎結合アーキテクチャを確立しています。
