本ディレクトリ（`iryo-kanri-system/iryo-domain/src`）は、医療管理システムの中核を成すビジネスロジックとドメイン知識を集約・管理するドメイン層のソースコードルートです。データベースやUI、外部フレームワークなどの技術的詳細から完全に隔離された純粋なドメインモデルを構築・維持することを目的としており、患者管理、診察予約、電子カルテ、医療費計算、病棟運用といった医療現場における広範な業務概念と厳密なビジネスルールを一元的に定義しています。

内部では基盤となる監査・識別エンティティ（`Entity`、`AuditedEntity`）を共通土台とし、中核となる患者（`Patient`）エンティティを中心に、診察予約（`Appointment`）や電子カルテの記録・アーカイブ（`ChartEntry`、`ChartArchive`）といった診療系コンポーネントが密接に協調しています。さらに、厳密な金銭計算を担保する値オブジェクト（`Money`）や病棟管理サブドメインが連携することで、患者の受け入れから診療追跡、病棟配置、会計処理に至る一連の医療業務プロセスが高い整合性をもって自己完結的に処理される構造を実現しています。

アーキテクチャ面ではドメイン駆動設計（DDD）の原則が徹底されており、エンティティと値オブジェクトの厳格な分離や、関心の分離（SoC）に基づくモジュール分割がなされています。また、スレッドセーフ性と安全性を高めるイミュータブルパターンの採用、Static Factory MethodやPrototypeパターンによる安全なオブジェクトライフサイクル管理、内部クラスによる詳細のカプセル化など、医療ドメイン特有の高い信頼性要件を満たしつつ、将来の仕様変更や機能拡張にも柔軟に適応できる堅牢な設計判断が下されています。
