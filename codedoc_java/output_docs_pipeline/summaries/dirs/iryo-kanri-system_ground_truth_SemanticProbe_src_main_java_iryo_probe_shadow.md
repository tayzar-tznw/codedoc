本ディレクトリ（`iryo.probe.shadow`）は、Java言語仕様（JLS 6.4.1）に基づく名前解決ルールとスコープ遮蔽（シャドウイング）の挙動を実行時に検証・実証することを目的とした、セマンティック検証（SemanticProbe）用のモジュールです。受付端末等の業務ロジック実装において潜在的なバグとなり得る、静的インポート（static import）された外部メソッドと自クラス内で定義された同名メソッドの優先解決規則を明確化するためのテストケースとして機能します。

本モジュールの中心的なコンポーネントである `ShadowSide` は、外部の計算ユーティリティ `iryo.billing.PointMath` と相互作用します。クラス内部では同シグネチャの独自メソッドを定義し、非修飾呼び出しを行う `shadowed` メソッドでは自クラス側実装への遮蔽を、完全修飾名を用いる `imported` メソッドでは外部の正規処理へのバインドをそれぞれ明示的に分離して実装しています。これにより、同名シンボルの参照解決に伴う計算結果の差異（10倍計算と11倍計算の振る舞い）を実行時に比較検証できる構造になっています。

アーキテクチャ上の判断としては、不要な状態管理を排除し振る舞いの検証に特化させるため、`final` 修飾およびプライベートコンストラクタによるインスタンス化の抑止を施した Utility Class パターンを採用しています。スコープ競合の振る舞いを単一クラス内に局所化・カプセル化することで、外部システムへの副作用を防ぎつつ、言語仕様の境界条件を安全に検証可能な設計となっています。
