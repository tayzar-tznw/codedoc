`iryo-kanri-system/iryo-scheduling` モジュールは、医療管理システムにおける診療予約（スケジューリング）の受付から状態追跡、確定、そして患者への通知に至る一連のライフサイクル全体を管理・統括するモジュールです。患者の予約業務における中核ビジネスロジックを集約し、業務ルールの厳密な検証とデータ整合性の維持を通じて、円滑で信頼性の高いスケジューリング業務を提供することを目的としています。

本モジュール内部では、予約ドメインを管理するコンポーネントと外部連携を担うコンポーネントが明確な責務分担のもとで協調動作しています。中核を担う `AppointmentBook` が予約エンティティの集約や業務ルールの検証、ステータス遷移などのドメインロジックを一元管理し、予約確定といった主要なイベントの発生と連動して `SmsNotifier` が患者へのメッセージ送信をトリガーします。これにより、スケジューリング業務の進捗と患者への連絡処理が整合性を保ちながらシームレスに連携します。

アーキテクチャの観点では、関心の分離と将来の拡張性を重視した設計判断が下されています。`AppointmentBook` にはファーストクラスコレクションおよびインメモリ・リポジトリパターンが適用され、予約データの一貫性とドメインルールが強固にカプセル化されています。また、通知機能にはStrategyパターンを採用することで具体的な通信手段を抽象化し、ドメインロジックから外部通信実装を疎結合に切り離しています。これにより、中核ビジネスロジックに影響を与えることなく、永続化方式の刷新や新たな通知チャネルの追加に柔軟に対応できる保守性の高い構造を実現しています。
