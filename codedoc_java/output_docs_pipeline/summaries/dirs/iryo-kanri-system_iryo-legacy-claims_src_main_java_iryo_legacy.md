本モジュール（`iryo.legacy`）は、医療管理システムにおいて旧世代のレセプトコンピュータ（レセコン）や過去の請求仕様に対する後方互換性機能を一元管理・カプセル化するための基盤パッケージです。現行システムへの移行期間中におけるデータ照合や過去資産との連携、既存業務の継続性を担保することを主目的としており、レガシー固有の業務ロジックが現行のコア領域へ混入することを防ぐ隔離層としての役割を果たしています。

主要な構成要素である配下の `claims` パッケージでは、旧点数表を型安全に表現する `OldTable` や経過措置加算を含む計算処理を担う `PointTable` が算定の中核として機能します。算定対象や計算結果のデータは軽量な `ChartCache` を介して安全に保持・受け渡され、最終的にサブパッケージ内の `ReceiptFormatter` によって旧レセコン仕様に準拠したテキスト形式へと整形・出力されるという、一連のレガシー請求処理パイプラインが確立されています。

アーキテクチャ面では、将来的なレガシー機能の安全な廃止・切り離しを前提とした設計が徹底されています。クラスへの `@Deprecated` 付与や `final` 修飾による無秩序な継承・新規採用の抑止、外部依存を排除した自己完結型の実装、さらにはValue HolderやFormatterといった責務が限定的なパターンの適用により、最小限の影響範囲で旧仕様を保守・運用できる構造を実現しています。
