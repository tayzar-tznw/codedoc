`iryo-pharmacy` モジュールは、医療管理システムにおいて調剤業務および薬局ワークフローの中核を担うドメインモジュールです。その主たる目的は、処方指示の受け入れから適正投与量の算出、点数・金銭の費用計算、監査ログの保持に至る調剤業務のビジネスルールと計算エンジンを集約・カプセル化し、システム全体に対して安全で正確かつ一貫した調剤機能を提供することにあります。

モジュール内部では、調剤パイプラインの各フェーズに応じたコンポーネント群が有機的に連携します。処方指示データが入力されると、まず `Validator` が構文および業務制約の厳格な検証を実行してデータの妥当性を保証します。続いて、検証済みデータに基づき `DoseCalculator` が患者の身体特性に応じた適正投与量を算出し、その結果を受けて `PointMath` が薬価点数と換算レートに基づく費用計算を行います。算出された金銭情報は不変なドメインモデルである `Money` を介して安全に保持・管理され、これら一連の処理過程で生じたイベントは `Logger` によって追跡・記録され、業務上の監査性とトレーサビリティを確立します。

アーキテクチャ上の設計判断として、外部フレームワークへの依存を排した自己完結型のクリーンな設計が貫かれています。計算や検証を司るエンジンには副作用を持たないステートレスなユーティリティ設計を採用し、ドメインデータモデルには不変値オブジェクトパターンや防御的コピーを徹底することで、状態変更によるバグを排除しています。これにより、医療システムに不可欠な極めて高い計算精度とデータ整合性を担保しつつ、テスト容易性と長期的な保守性に優れた堅牢な構造を実現しています。
