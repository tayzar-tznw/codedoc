# iryo-kanri-system ドキュメント

## はじめに

本ディレクトリは、医療機関における受付、診療、調剤、会計、予約、管理業務、および外部システム連携にいたる一連のライフサイクルを包括的に支える、堅牢で拡張性の高い医療管理システムのルートディレクトリです。システムは、ビジネスロジックの中核を担う「`domain`」「`billing`」「`pharmacy`」「`scheduling`」などのドメインパッケージと、それらを支える共通基盤である「`kernel`」「`data`」「`interop`」、さらに具体的なエンドユーザー向けアプリケーションである「`admin-console`」「`patient-portal`」「`reception-desk`」などの実行レイヤーに明確に分離されています。これらは、患者の来院から受付、診察、調剤、会計、そして日次・月次の管理レポート生成にいたる業務フローに沿って有機的に連携し、一貫した医療サービスを提供します。

アーキテクチャの観点では、ドメイン駆動設計（DDD）とクリーンアーキテクチャの原則が徹底されています。ビジネスルールは「`domain`」にリッチドメインモデルとしてカプセル化され、
